# T-003 · Room gate at arrangement level, calibrated

status:     open
priority:   medium
subsystem:  state

what:
Measure the room gate against the vanderbilt6 paintings and set its criterion so that it flags a different room and does
not flag a restyled one. Keep the question at arrangement level (the same kinds of fixtures in the same places, the same
kind of wall finish), make `added` mean "no counterpart in the plate", and decide whether a shifted fixture (a fireplace
right of both windows instead of between them) is a flag or a note. Record the verdicts of both criteria on every painted
still of the run and pick the one the user agrees with.

why:
The first criterion compared craftsmanship and flagged a correct Lincoln single for its mantel carving and clock design.
The arrangement criterion still flagged two of three repaints: a window missing at a frame edge, a fireplace shifted right
of two windows. Both were tolerable to a viewer, while the wallpaper single that started the problem would be flagged by
either. The gate must inform the user's decision, not drown it.

acceptance:
On vanderbilt6: the wallpaper s1-3-t2 flagged; s1-3-r1, s1-4-r1, s1-5-r1 passed or noted, not flagged; the verdicts and the
reasons written in the run record.
