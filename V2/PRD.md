# V2 PRD → see `prd/`

The product requirements are a directory now, one file per subsystem. Start with `prd/00-overview.md` (the data flow, the
principles, how the subsystems work together), then `01-story.md`, `02-assets.md`, `03-screenplay.md`, `04-state.md`,
`05-keyframes.md`, `06-sound.md`, `07-edit.md`, `08-costs.md`, `09-status.md`, `10-decisions.md`, `11-agent.md` (the agent in front of the
chain: universal questions, tools, session, editing).
