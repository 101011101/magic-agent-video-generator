# drafts — draft code and draft design

Material that informs V2 but is not part of it yet, or is kept for reference:

- `CASES.md`: the media cases (drama, ad, short, vlog, explainer, documentary, streamer, music video, trailer, news,
  storybook, walkthrough, presenter) with what each demands, the audit of the v2 screenplay prompt against them, and the v3
  schema sketch (camera motion, shot kinds, overlays, narration, screens, items). The source for ticket T-004.
- the archived PRDs from `V1/docs/` (PRD v4 for the keyframe chain, the two approach drafts, the testing to-do, the
  call audit): where a rule in `../prd/` came from.
- draft code: anything tried on the side before it earns a place under `../src/`. A draft that is run must still go through
  `src/lib/jobs.js` so its credits are in the ledger.

Nothing here is run by the pipeline. When a draft becomes real, it moves to `../src/` and its ticket closes.
