How to read this

  • Within a group every row shares the prompt, aspect, resolution and image count. The only difference between rows is the model, so a difference in verdict is a difference between models.
  • est. is the spec's “from N credits/image” floor; charged is what Magic Hour actually billed. They differ: the ledger shows nano-banana-pro billing 200 at 2k against a documented 150.
  • A not scored verdict means the frame exists but the vision judge did not run or failed — the credits were still spent. It is not a pass.
