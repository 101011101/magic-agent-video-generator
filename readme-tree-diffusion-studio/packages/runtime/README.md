# `packages/runtime`

`@diffusionstudio/runtime`: the headless editor engine. A koota ECS world holds the composition as entities with traits; five deterministic systems turn that world into a drawn frame and scheduled audio on host-injected surfaces. No DOM dependency, no solid-js.

## How it works

- Host creates a world with `createRuntimeWorld(projectId)`. The world owns one stage entity (`Stage`, `Camera`, `Background`) pointed to by `Root`. Host then sets `RenderSurface` (canvas + ctx + pixel ratio), `AudioEngine` (`AudioContext` or `OfflineAudioContext`), `Library` (`AssetLibrary` from `packages/assets`), optionally `Ai` (`GenAi`), and `Mode` (`realtime` | `offline-video` | `offline-audio`).
- The reconciler (`packages/reconciler`) mounts a project by spawning entities with traits and `ChildOf` relations. Each entity keeps a `Host` trait pointing at its document node.
- `observeWorld` reacts to structural and value changes: `ChildOf` add/remove rebuilds `Cache` lists (fills, strokes, effects, keyframe tracks, ...), propagates size and constraints, recomputes time ranges up and down the tree, syncs stage playback, and disposes decoders on removal.
- Each tick the host runs systems in this order: `assetSystem` -> `playbackSystem` -> `motionSystem` -> `transformSystem` -> `renderSystem`.
  - `assetSystem` resolves pending source requests through `Library.resolve` and `Ai.resolve`, binds `AssetId`, and aligns `syncTo` clips via audio cross-correlation.
  - `playbackSystem` advances `Playback` playheads by `Time.delta` (realtime only), writes `Computed.localTime`/`visibility` per node, forwards video/audio/caption/shader decoders to the current frame, applies `Transition` windows between sequential siblings, syncs and solos `AudioBus` nodes, then fires `Tickers`.
  - `motionSystem` resets `Computed` from authored traits, then applies preset `Animation`s (in/out phases) and `KeyframeTrack` samples.
  - `transformSystem` walks the tree: `computeGroupBounds`, `computeLocalMatrix`, `computeWorldTransform`, `computeWorldBounds`, `cullEntity` (`Culled` tag), then adjustment layers.
  - `renderSystem` clears the canvas, paints `Background` and camera view (realtime only), draws every non-culled top-level node via `renderNode` (fills, strokes, shadows, effects, masks, clip paths, captions, HTML/shader paints), and pushes callback-less `HitRegions` for `Interactive` entities.
- Derived data lives in `Computed` and `Cache` SoA stores, written through `store()` without change events. Authored traits stay the source of truth for serialization.
- Offline capture: the encoder sets the playhead per frame, systems push decoder readiness promises into `FramePromises`, the encoder awaits them before sampling the canvas and audio.
- Every media decoder is lazy: `resolveVideoDecoder`, `resolveAudioDecoder`, `resolveImageDecoder`, `resolveCaptionDecoder`, `resolveShaderHost` create a handle on first use and reuse it. `handOffDecoders` transfers warm video decoders to a split clip.

## Interfaces

- Depends on: `packages/jsx` ([../jsx/README.md](../jsx/README.md)) for `AssetRef`, `generate.*`/`transform.*`, `SceneNode`; `packages/assets` ([../assets/README.md](../assets/README.md)) for `Asset`, `AssetLibrary`; koota (ECS; root `patches/koota+0.6.6.patch`), mediabunny (demux/decode/transcode), animejs (easing), colord (color parsing). Browser APIs at runtime: Canvas 2D / OffscreenCanvas, WebCodecs `VideoFrame`, Web Audio, optional WebGPU (`ShaderHost`).
- Used by:
  - `packages/reconciler` ([../reconciler/README.md](../reconciler/README.md)) `src/mount.ts`, `src/document.ts`: spawns entities and sets traits.
  - `packages/encoder` ([../encoder/README.md](../encoder/README.md)) `src/encoder.ts`, `src/image-encoder.ts`, `src/contact-sheet.ts`: runs the five systems offline against `OfflineAudioContext` and a capture canvas.
  - `apps/web` ([../../apps/web/README.md](../../apps/web/README.md)) `src/engine/create-engine.ts` `runSystems()` runs the same five systems between its own `inputSystem`/`shortcutSystem` and `hudSystem`/`timelineSystem`; `src/engine/*`, `src/dapi/handlers/*` (media tools use `transcode.ts`, `audio-peaks.ts`), inspector and timeline components use actions, queries, traits.
  - Solid reactivity over these traits comes from `packages/koota-solid` ([../koota-solid/README.md](../koota-solid/README.md)), not from this package.
