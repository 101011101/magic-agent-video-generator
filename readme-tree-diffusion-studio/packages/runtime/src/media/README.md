# `packages/runtime/src/media`

Lazy, per-entity media decoders and the audio graph: turns an entity's `AssetId` into a bitmap (video, image, sequence, mask, shader, waveform), scheduled Web Audio buffers, or caption text for the systems to draw; plus offline helpers (filmstrip, waveform, transcode, audio sync).

## Parts

| Part | Role |
|---|---|
| `index.ts` | Barrel. `export *` from every file below and from `caption/`. Exposed to hosts as `@diffusionstudio/runtime/media`. |
| `video.ts` | `resolveVideoDecoder(world, entity)`: picks one `VideoDecoderInstance` (`VideoBuffer` \| `VideoExporter` \| `SequenceDecoder` \| `MaskDecoder`) by asset type and `Mode` (`realtime` -> `VideoBuffer`, else `VideoExporter`), stores it in `VideoDecoderHandle`, pushes `frameRate` from `getSequenceFrameRate` on every call for sequence/mask. `VideoBuffer`: preview decoder over mediabunny `EncodedPacketSink` + WebCodecs `VideoDecoder` (inner `VideoDecoderQueue`, backpressure at `decodeQueueSize > 2`). Windowed `FrameCache` (30..81 tiles, budget `768*432*81` px), forward bias 24 frames, backward drain 8, display tolerance 4. Scrub path: seeks < 250 ms apart with a jump > 24 frames paint the covering keyframe from `KeyframeIndex.floor`, then `SCRUB_SETTLE_MS = 120` re-runs `exactSeekTo`. `touch()` arms a 10 s idle timer; `idle()` frees cache, decoder, iterator but keeps the display canvas. `VideoExporter`: full-resolution `CanvasSink` (`poolSize: 2`), sequential `seekTo` walking forward, re-seeds only on backward seek. `getVideoTrack` caches one `InputVideoTrack` promise per asset id; `clearVideoTrackCache`. |
| `sequence.ts` | `SequenceDecoder` for `SEQUENCE` assets: lists image files (`png\|jpe?g\|webp\|avif\|bmp\|gif`) from `asset.directoryHandle`, natural-sorts by name, `createImageBitmap` per frame. With `hasCache` uses a `FrameCache({pixels: 720*720, count: 49})` and the same 2/3-ahead window, generation-cancelled fills, 10 s idle; without cache (export) decodes the one target frame into `canvas`. `frameRate` is public and re-read on each `seekTo`. |
| `mask.ts` | `MaskDecoder` for `MASK` assets: reads a `MaskFile` (`@diffusionstudio/assets`) once; `seekTo` decodes one frame's run-length field into an `Int8Array` (clamped to `[0, frameCount-1]`); `getOutline(smoothing)` traces it with `traceMask` into a `Path2D` scaled to a canvas whose short side is 512 px (`MaskOutline`); `toBitmap()` fills the outline white at `DEFAULT_MASK_SMOOTHING`. `isStale(asset)` compares `asset.stat` after an error. |
| `frame-cache.ts` | `FrameCache`: tile atlas on an `OffscreenCanvas`. `insert(frame, index)` scales to `config.pixels`, rotates by `rotation` (90/270 swap), evicts tiles outside `[leftFrameIndex, rightFrameIndex]` when full. `has`, `findTile` (x, y, w, h), `findNearest(index, tolerance)` (ties go to the earlier frame), `dispose`. |
| `keyframe-index.ts` | `KeyframeIndex`: async walk of every key packet's timestamp (`EncodedPacketSink.getFirstKeyPacket/getNextKeyPacket`, `metadataOnly`), yielding to a macrotask every 512 packets. `floor(seconds)` = binary search; returns `null` before the first keyframe or past the walked range while incomplete. `getKeyframeIndex(assetId, track)` shares one index per asset; `clearKeyframeIndexCache`. |
| `image.ts` | `resolveImageDecoder(world, entity)` -> `{decoder, initPromise}` for `IMAGE` assets. `BitmapImageDecoder` (`createImageBitmap`) for raster; `ElementImageDecoder` (`HTMLImageElement` + object URL, pins `width`/`height` from the asset) for `image/svg+xml`. `SharedImageDecoder` is a refcounted per-entity handle over a per-world `WeakMap<World, Map<assetId, entry>>`; the last `dispose()` closes the bitmap. `getBitmap(w, h)` ignores size today (mipmap TODO). |
| `audio.ts` | `AudioDecoder`: `init()` gets the primary audio track (`getAudioTrack`, cached per asset id; `clearAudioTrackCache`) and an `AudioBufferSink`. `playTo(bus, {relativeFrom, relativeTo, trimStart, trimEnd, playbackRate, currentTime, relativeDelay})` iterates `sink.buffers(relativeFrom)` under an `AsyncMutex`, fills sample gaps with silence, runs samples through `TimeStretcher(1/playbackRate)`, and schedules each chunk as an `AudioBufferSourceNode` on `bus.input` (trimmed to clip window, clamped to `context.currentTime`, shifted by half a sample to avoid boundary clicks). `reset()` stops all nodes and drops the iterator. `resolveAudioDecoder(world, entity)` -> `{decoder, initPromise}` for `AUDIO` or `VIDEO`-with-channels assets on `AudioDecoderHandle`. |
| `time-stretcher.ts` | `TimeStretcher(channels, sampleRate, factor)`: WSOLA-style pitch-preserving stretch. Hop = `512 * sampleRate / 48000`, window = 2 hops, Hann-like crossfade over the overlap, adaptive-step + fine cross-correlation search for the best splice offset. `append(buffers)` returns synthesized output or `null`; `finalize()` flushes. `factor === 1` passes through. |
| `audio-bus.ts` | `AudioBus(world, entity)`: one `GainNode` per clip or scene on `AudioEngine.context`. `sync()` sets gain from `Computed.volume[entity]` in dB (`10^(dB/20)`, `-Infinity` or `Muted` -> 0). `connect(node)`, `mute()`, `disconnect()`, `input`. No per-track sub-mix; child buses connect into the parent bus. |
| `audio-peaks.ts` | `Waveform(asset, cache?)`: loads peaks via `AssetCache.peaks` when a `Library.cache` exists, else `derivePeaks(file)`. `resolveWaveformPeaks(world, fill)` returns `Uint8ClampedArray \| null` synchronously for the render loop and stores the loader on `WaveformHandle`. |
| `audio-sync.ts` | `computeAudioSyncOffset(audioAsset, videoAsset)` -> `{offsetSeconds, confidence}`. 500 Hz RMS envelopes (`AudioSampleSink`), radix-2 FFT cross-correlation, Pearson NCC per lag from prefix sums, min overlap 1 s, no-match floor 0.1, parabolic sub-bin refinement. Asserts loudly on no audio, no overlap, or weak match. `computeAudioSyncOffsetCached` memoizes by `a.id:b.id`. |
| `shader.ts` | `ShaderHost`: WebGPU pipeline for one shader paint. `setCode(code)` compiles `PRELUDE + code` (prelude: `Globals` uniform, `source` texture + sampler at `@group(0)`, fullscreen triangle `vs`, `sampleSource(uv)` honoring `fitOffset`/`fitSize`); parses `@group(1) @binding(n) var<uniform>` slots (`f32`, `vec2f..vec4f`) into one `GPUBuffer` each. `draw(ctx, w, h, source, sw, sh, fit, time, uniforms)` uploads `source` via `copyExternalImageToTexture`, writes globals and named uniforms (numbers, arrays, or CSS color strings through `parseColor`), renders to an offscreen `webgpu` canvas, then `ctx.drawImage`s it. Returns `false` (caller draws media directly) when no pipeline. One shared `GPUDevice` per page. `resolveShaderHost(world, entity)` stores it on `ShaderHostHandle` when `Shader.code` is set. |
| `html.ts` | `whenHtmlReady(root, seconds)`: pauses every animation under `root` and sets `currentTime`, awaits `document.fonts.ready` and pending `img.decode()`, then `nextRenderingUpdate()` (rAF + 250 ms fallback). `isHtmlInCanvasSupported()` checks `drawElementImage` on `CanvasRenderingContext2D`. |
| `transcode.ts` | Worker-capable mediabunny helpers. `transcodeForTranscription(asset)` -> mono 16 kHz Opus `.ogg` `File`, video discarded. `transcodeForAnalysis(asset, window?)` -> `{readable, run}` streaming fragmented MP4 (640 px, 24 fps, 500 kbps) or Opus Ogg, trimmed to `TimeWindow`. `filmstripAsset(asset, {start?, end?, scale?})` -> PNG data URL grid of thumbnails on a 28 px token grid (max 64x52 tokens) with a timecode ruler. `waveformAsset` -> data URL waveform plus `silences[]` (peak <= 12/255 for >= 0.4 s, drawn red). `stampTimestampLabel(ctx, height, label)` draws an outlined timecode in a corner. |
| `handoff.ts` | `handOffDecoders(world, from, to)`: moves `VideoDecoderHandle` values from `from`'s subtree to `to`'s, node by node, only where both `AssetId`s match and subtree child counts match. Nulls the source trait (so its `onRemove` does not dispose the moved decoder). Audio is left in place. |
| `dispose.ts` | `disposeDecoders(world, entity)`: recursively disposes/resets `ImageDecoderHandle`, `VideoDecoderHandle`, `AudioDecoderHandle`, `CaptionDecoderHandle`, `WaveformHandle` and sets each to `null`. `disconnectAudioBus(world, entity)`: same walk for `AudioBusHandle`. For still-alive entities (culling, re-parenting); deletion relies on trait `onRemove` hooks instead. |
| [caption/](caption/README.md) | Seven `CaptionDecoder` presets that turn a `TRANSCRIPT` asset into timed `Chars`/`TextRange`/paint children on a `<captions>` entity. `resolveCaptionDecoder`, `CAPTION_PRESET_STYLES`, `CAPTION_PRESET_FILLS`, `placeCaption`, `parseSubtitles`. |

## How it works

- Every decoder follows one pattern: `resolve*(world, entity)` reads `AssetId`, returns the handle trait's value when its asset id still matches, else disposes it and constructs a new one from `getAsset(world, id)`. Construction starts async init (`initialized` / `initPromise`); the render loop reads synchronously and gets `null` until ready.
- Bytes come from `actions/assets.ts` `getAssetFile(asset)`. mediabunny `Input` + `BlobSource` demuxes; per-asset track promises (`getVideoTrack`, `getAudioTrack`) and `KeyframeIndex` are shared across decoders of the same asset.
- Video per frame: `systems/playback.ts` calls `resolveVideoDecoder(...).seekTo(frame, fps)` and pushes any returned promise into `FramePromises` (offline encode awaits them). `systems/render.ts` calls `toBitmap()` and draws the returned canvas; for masks it asks `MaskDecoder.getOutline(smoothing)` first.
- `VideoBuffer.seekTo` converts scene frame -> source frame via `asset.frameRate`, decides scrub vs exact seek, computes the cache window (`2/3` ahead in seek direction), and chains `fillCache` runs on `seekLock` (never concurrent; superseded by `seekGeneration`). Decoded `VideoFrame`s land in `FrameCache` through `frameCallback`; `toBitmap` blits the nearest cached tile within 4 frames.
- Export path: `Mode !== 'realtime'` picks `VideoExporter` (no cache, ordered `CanvasSink`) and `SequenceDecoder` with `hasCache = false`.
- Audio: `playback.ts` creates one `AudioBus` per clip/scene on `AudioBusHandle`, connects children into parents, then calls `AudioDecoder.playTo(bus, options)` to schedule buffers ahead of `context.currentTime`. Each tick `bus.sync()` applies `Computed.volume`; solo logic calls `mute()`. `TimeStretcher` runs when `playbackRate !== 1`.
- Images: `resolveImageDecoder` shares one decode per asset per world (refcount); `render.ts` calls `getBitmap(w, h)`.
- Shader paints: `playback.ts` awaits `resolveShaderHost(...).whenReady()`; `render.ts` samples the media paint below the shader into `host.draw(...)`, falling back to drawing the media directly when `ready` is false.
- HTML paints: `playback.ts` pushes `whenHtmlReady(root, localTime)` into `FramePromises` so fonts, images, and paused animations are settled before capture.
- Waveform paints: `render.ts` calls `resolveWaveformPeaks` and draws the peaks; `null` until loaded.
- Lifecycle: `world/observers.ts` disposes handles on trait remove (`onRemove(VideoDecoderHandle, ...)`, `AudioBusHandle.disconnect`) and calls `disposeDecoders` on `Culled` add; `handOffDecoders` keeps a warm `VideoBuffer` on the half of a split that plays next.
- Offline analysis (`transcode.ts`, `audio-sync.ts`) does not touch entities: it opens its own `Input`, renders to an `OffscreenCanvas` or computes envelopes, and disposes the input.

- Depends on:
  - `packages/runtime/src/traits/media.ts` handle traits (`VideoDecoderHandle`, `AudioDecoderHandle`, `ImageDecoderHandle`, `WaveformHandle`, `AudioBusHandle`, `ShaderHostHandle`, `CaptionDecoderHandle`) and `traits/` `AssetId`, `Mode`, `Muted`, `Computed`, `AudioEngine`, `Library`, `Shader`, `ChildOf` (see [../traits/README.md](../traits/README.md)).
  - `packages/runtime/src/actions/assets.ts`: `getAsset`, `getAssetFile`, `getSequenceFrameRate`.
  - `packages/runtime/src/queries/hierarchy.ts` `getEntityChildren`; `world/store.ts` `store`; `utils/async.ts` `AsyncMutex`, `attempt`; `utils/assert.ts`; `utils/time.ts` `formatTimestamp`; `utils/color.ts` `parseColor`.
  - `packages/assets` ([../../../assets/README.md](../../../assets/README.md)): asset types, `MaskFile`, `traceMask`, `DEFAULT_MASK_SMOOTHING`, `MASK_FIELD_MAX`, `derivePeaks`, `AssetCache`.
  - `mediabunny` (`Input`, `BlobSource`, `EncodedPacketSink`, `CanvasSink`, `AudioBufferSink`, `AudioSampleSink`, `Conversion`, `Output`); `koota`. Browser: WebCodecs `VideoDecoder`/`VideoFrame`, `OffscreenCanvas`, Web Audio, File System Access (`directoryHandle`), optional WebGPU.
- Used by:
  - `packages/runtime/src/systems/playback.ts`: all `resolve*` functions, `AudioBus`, `AudioDecoder.playTo`, `whenHtmlReady` (see [../systems/README.md](../systems/README.md)).
  - `packages/runtime/src/systems/render.ts`: `resolveVideoDecoder`, `resolveImageDecoder`, `resolveShaderHost`, `resolveWaveformPeaks`, `resolveCaptionDecoder`, `MaskDecoder.getOutline`.
  - `packages/runtime/src/systems/assets.ts`: `computeAudioSyncOffsetCached` for `SyncRequest`.
  - `packages/runtime/src/world/observers.ts`: `disposeDecoders`, `disconnectAudioBus`.
  - `packages/encoder/src/encoder.ts` (`new AudioBus` for the scene), `packages/encoder/src/contact-sheet.ts` (`stampTimestampLabel`) ([../../../encoder/README.md](../../../encoder/README.md)).
  - `apps/web/src/engine/split.tsx` (`handOffDecoders`), `apps/web/src/engine/capture.ts` (`disposeDecoders`), `apps/web/src/dapi/handlers/media-filmstrip.ts`, `media-waveform.ts`, `media-transcribe.ts`, `media-listen.ts` (`filmstripAsset`, `waveformAsset`, `transcodeForTranscription`, `transcodeForAnalysis`).
  - `isHtmlInCanvasSupported`, `clear*Cache` functions, `TimeStretcher`, `VideoExporter`: no caller found outside this directory.
