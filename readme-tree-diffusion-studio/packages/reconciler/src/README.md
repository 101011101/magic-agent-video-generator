# `packages/reconciler/src`

Evaluates a compiled project bundle, binds it to Solid's universal renderer, and reconciles its JSX element tree onto `@diffusionstudio/runtime` ECS entities (koota) in one world.

## Parts

| Part | Role |
|---|---|
| `index.ts` | Package entry. Re-exports all of `document.ts` and `elements.ts`, plus `evaluate`, `collectInspect`/`InspectEntry`, `mount`/`Mount`, `insert`/`renderProject`/`withDocument`, `JSX_RUNTIME`, and types `ProjectDocument`/`ProjectTick`. |
| `host.ts` | Types only. `ProjectDocument<N>`: the host interface Solid's `createRenderer` writes into (`stage`, `createElement`, `createTextNode`, `replaceText`, `isTextNode`, `setProperty`, `insertNode`, `removeNode`, `getParentNode`, `getFirstChild`, `getNextSibling`; optional `tick`, `hold`, `resolution`, `applyRef`). `ProjectTick`: `{ time, frame, delta, playing }`, one playhead reading. |
| `evaluate.ts` | `evaluate(code)`: runs a CommonJS bundle with `new Function('require','module','exports', code)`. `require` resolves only `solid-js`, `solid-js/store`, and `@diffusionstudio/jsx` (bound to `JSX_RUNTIME`); anything else throws. Returns `module.exports.default`; throws if it is not a function. |
| `runtime.ts` | `JSX_RUNTIME`: the object a bundle sees as `@diffusionstudio/jsx`. Spreads the authoring package (`@diffusionstudio/jsx`), then `elements.ts`, then the renderer bindings (`render`, `effect`, `memo`, `createComponent`, `createElement`, `createTextNode`, `insertNode`, `insert`, `spread`, `setProp`, `mergeProps`, `use`, `useResolution`, `useTicker`, `__inspect`). Later spreads win, so the live hooks replace the throwing declarations in `@diffusionstudio/jsx`. |
| `renderer.ts` | Module-level singleton `createRenderer<unknown>(...)` from `solid-js/universal`. Every host op calls `doc()` = `useContext(DocumentContext) ?? currentDocument`, then forwards to that `ProjectDocument`. Exports the renderer's `render`, `effect`, `memo`, `createComponent`, `createElement`, `createTextNode`, `insertNode`, `insert`, `spread`, `setProp`, `mergeProps`. `use(fn, node)`: routes `ref={fn}` through `document.applyRef` if present. `useTicker()`: four `createMemo`s over `document.tick()` plus `hold`. `useResolution()`: memo over `document.resolution()`, default 1. `withDocument(document, fn)`: sets `currentDocument` for the call. `renderProject(project, document)`: `render(...)` into `document.stage` under `DocumentContext.Provider`; returns Solid's disposer. |
| `elements.ts` | PascalCase host components: the compile target the CLI rewrites camelCase tags into (`<rect>` -> `Rect`). `hostElement(tag)` builds a component that calls `createElement(tag)`, applies `ref` via `use`, and `spread`s the rest. Exports `Stage`, `Scene`, `Group`, `Rect`, `Video`, `Image`, `Audio`, `Text`, `TextRange`, `Sequence`, `Captions`, `AdjustmentLayer`, `SolidPaint`, `LinearGradientPaint`, `RadialGradientPaint`, `ImagePaint`, `VideoPaint`, `ColorStop`, `Stroke`, `Shadow`, `Effect`, `Mask`, `Animation`, `KeyframeTrack`, `Keyframe`, `HtmlPaint`, `Html`, `ShaderPaint`, `SurfacePaint`, `Surface`. `renderAuthored(tree)`: builds host nodes from an `AuthoredTree` statically (element, `setProp` per prop, text node, children). |
| `document.ts` | `RuntimeDocument implements ProjectDocument<SceneNode>`: the host over the ECS world. Largest file; see "How it works". Also exports `createRuntimeDocument(world)` (one per world, throws on a second), `getRuntimeDocument(world)`, `authoredElement(entity)`, `authoredTree(world, entity)`, `isSceneNode`, `trackPropertyPath(holder, property)`, `trackProperty(path)`, and the prop-name-to-runtime-enum maps `TRANSITION_TYPES`, `BLEND_MODES`, `HORIZONTAL_CONSTRAINTS`, `VERTICAL_CONSTRAINTS`, `EASINGS`, `ANIMATION_TYPES`, `CAPTION_PRESETS`, `CAPTION_ALIGNS`, `EFFECT_TYPES`. |
| `inspect.ts` | `__inspect(declaration, initial)`: the live implementation of a compiled `@inspect` variable. Creates a `createSignal` pair (`get`/`set`) and a `committed` signal, pushes an `InspectEntry` (`file`, `name`, `type`, `label`, `group`, `min`/`max`/`step`/`options`, `initial`, `get`, `set`, `committed`, `commit`) onto the current collector, returns `get`. `collectInspect(fn)`: runs `fn` and returns `{ result, entries }` gathered in declaration order. |
| `mount.ts` | `mount(code, world): Mount`. Sequence: `collectInspect(() => evaluate(code))` -> `createRuntimeDocument(world)` -> `renderProject(component, document)` (on throw: `document.dispose()` then rethrow) -> adds `document.advanceTicker` to `world.get(Tickers)`. `Mount.dispose()` removes the ticker, calls Solid's disposer, then `document.dispose()`. `Mount.inspect` holds the entries. |

## How it works

- Compile side (outside this package): `apps/desktop/src/projects.ts` runs `babel-preset-solid` with `generate: "universal"`, `moduleName: "@diffusionstudio/jsx"`, and marks `solid-js`, `solid-js/*`, `@diffusionstudio/jsx` external. The bundle therefore imports element components and runtime ops by name from `@diffusionstudio/jsx`.
- `mount(code, world)`:
  - `evaluate` runs the bundle. Its `require('@diffusionstudio/jsx')` returns `JSX_RUNTIME`, so the bundle uses the host's `solid-js` instance and this package's element components and hooks. `collectInspect` wraps this call and captures each `__inspect` call as an `InspectEntry`.
  - `createRuntimeDocument(world)` builds a `RuntimeDocument`. Its `stage` node wraps `world.get(Root)` and puts a `Host` trait on it.
  - `renderProject` calls Solid's `render` into `document.stage` with `DocumentContext` set. Every renderer op (`createElement`, `setProperty`, `insertNode`, ...) reaches `RuntimeDocument` through `doc()`.
- `RuntimeDocument.createElement(tag)`:
  - Lowercase tag = DOM content (under `<html>`/`<htmlPaint>`): creates a real DOM element (SVG namespace when `SVGElements.has(tag)`), an entity with `Host`, `native: false`. Rejects `audio`, `video`, `canvas`.
  - PascalCase tag = composition element: lowercases the first letter, then `switch`es on the name and creates an entity with that element's traits. Examples: `scene` -> `Geometry(RECT)`, `Position`, `Scene`, `ClipsContent`, `Playback`, 1920x1080; `text` -> `Geometry(TEXT)`, `Position`, `Chars`, `TextStyle`; `video`/`image` -> `Paint(VIDEO|IMAGE)`; paints (`solidPaint` ... `videoPaint`) -> `Paint(PAINT_TYPES[name])`; `htmlPaint`/`html` -> a `div` appended to `world.get(RenderSurface).canvas`; `surface`/`surfacePaint` -> a `canvas` element; `stroke`, `shadow`, `effect`, `mask`, `animation`, `keyframeTrack`, `keyframe`, `colorStop`, `textRange`, `captions`, `adjustmentLayer`, `group`, `sequence`, `audio`. `stage` returns the existing stage node. Unknown tag throws.
  - Each created entity gets a `SceneNode` `{ entity, native, tag, props, parent, children, element }` stored in its `Host` trait.
- `RuntimeDocument.setProperty(node, name, value)`:
  - For DOM nodes: `setDomProperty` handles `style`, `class`/`className`, `classList`, `innerHTML`, `textContent`, plain attributes; ignores functions and `on*`.
  - Records the authored prop in `node.props` (except `__source`, `__loop`, `children`, `ref`, and never on the stage).
  - `switch`es on `name` and adds/sets/removes the runtime trait: `x`/`y` -> `Position`; `rotation` -> `Rotation`; `scale` -> `UniformScale`; `width`/`height` -> `resizeEntity` (or `StrokeStyle.width` on a stroke); `fill`/`color` -> `Color` via `parseColor`; `src` -> `bindAsset` if `getAsset` knows it, else `LoadRequest` (string) or `GenerationRequest` (object ref); `start`/`end`/`sourceIn`/`sourceOut`/`playbackRate` -> `syncTiming` derives `Delay` and `Trim`; `cornerRadius*` -> `syncCornerRadii` derives `MixedCornerRadius`; `keepAspectRatio` -> `syncAspectLock`; `preset` on captions writes `CAPTION_PRESET_STYLES`/`CAPTION_PRESET_FILLS` then re-applies `CAPTION_OVERRIDE_PROPS`; `property` on a track -> `resolveTrackProperty` via `trackPropertyPath`; `background` and `camera` write world-level state; `timeline`/`playhead` call `setTimelineView`/`setPlayhead`. Unknown props are ignored.
  - Time props go through `parseTime` (from `@diffusionstudio/jsx`) then `toFrames` = `secondsToFrames(seconds, world.get(FrameRate).value ?? 30)`.
- `RuntimeDocument.insertNode(parent, node, anchor)`:
  - Writes `parent.children` first, then derives ECS traits: `removeChild`/`appendChild` for the parent link, `ItemIndex` over native siblings in order. Re-resolves a `KeyframeTrack`'s property on insert (the holder is known only now).
  - DOM text/element nodes go into the DOM container of `<html>`/`<htmlPaint>`; a text node under a `<text>` updates `Chars` via `syncChars`; a text node elsewhere is an inert placeholder. Throws on composition under DOM, DOM outside `<html>`, and cycles.
- `removeNode` detaches and destroys the subtree (`entity.destroy()`, `element.remove()`); the stage is cleared, not destroyed.
- Ticker: `world.get(Tickers)` holds `document.advanceTicker`; `packages/runtime/src/systems/playback.ts` calls every ticker once per tick. `advanceTicker` reads `Computed.localTimeInSeconds`/`localTime` and `Playback.playing` from `tickTarget()` (nearest `Playback` carrier at or above `getActiveEntity`, else first `Playback`), writes the `ticker` signal (custom `equals` so a paused scene does not propagate) and `resolutionSignal`. `useTicker()` memos re-run before motion/render systems.
- `hold(work)`: pushes `Promise.race([work, 30s timeout])` onto `world.get(FramePromises).list` for offline export; no-op in realtime (list is null). `resolution()` returns `RenderSurface.resolution` while exporting, 1 in `Mode` `realtime`.
- Editor use (not a mount): `withDocument(document, () => insert(document.node(parent), element, anchor))` lets `apps/web` create elements through the same renderer ops; `renderAuthored(authoredTree(world, entity))` duplicates a subtree; `authoredElement(entity)` reads back `{ tag, props, text }` for writing edits to source.
- `dispose()`: destroys every live non-`IsExcluded` entity except the stage, revokes `HTMLImageElement` object URLs, removes DOM elements, and frees the world's document slot.

## Interfaces

- Depends on:
  - `solid-js`, `solid-js/universal` (`createRenderer`), `solid-js/store`, `solid-js/web` (`SVGElements`): reactive graph and host-agnostic renderer.
  - `koota` (`World`, `Entity`, `IsExcluded`): ECS.
  - [`packages/runtime/src`](../../runtime/src/README.md): all traits (`Host`, `Root`, `Tickers`, `FramePromises`, `RenderSurface`, `Mode`, `FrameRate`, `Computed`, `Playback`, `Geometry`, `Position`, `Paint`, `Color`, `TextStyle`, `Chars`, `Caption`, `Animation`, `Keyframe`, `KeyframeTrack`, `Delay`, `Trim`, ...), actions (`createEntity`, `appendChild`, `removeChild`, `resizeEntity`, `bindAsset`, `getAsset`, `setPlayhead`, `setTimelineView`, `setCameraMatrix`, `secondsToFrames`, `parseColor`), tree queries (`getParentEntity`, `getParentNode`, `getEntityChildren`, `getEntityTree`, `getActiveEntity`), `CAPTION_PRESET_STYLES`/`CAPTION_PRESET_FILLS`, and type `SceneNode` (`packages/runtime/src/traits/document.ts`).
  - [`packages/jsx/src`](../../jsx/src/README.md): authoring surface spread into `JSX_RUNTIME`; `parseTime`, `SOURCE_ATTR` (`__source`), `LOOP_ATTR` (`__loop`); prop types for `elements.ts`; `Ticker`, `InspectDeclaration`, `InspectType`, `InspectValue`, `AnimatableProperty`, `AssetRef` types.
  - `@diffusionstudio/assets`: `DEFAULT_MASK_SMOOTHING`.
- Used by:
  - `apps/web/src/pages/editor.tsx`: `mount(code, world)` per bundle, `Mount.inspect` -> inspector, `Mount.dispose()` on unmount.
  - `apps/web/src/engine/capture.ts`: `mount` into a throwaway world for offline capture.
  - [`apps/web/src/engine`](../../../apps/web/src/engine/README.md): `editor.ts` uses `getRuntimeDocument`, `withDocument`, `insert`, `renderAuthored`, `authoredTree`, `authoredElement`, `isSceneNode`, types `RuntimeDocument`/`ProjectDocument`/`AuthoredTree`; `history.ts`, `keyframes.tsx` (`trackPropertyPath`), `group.tsx`, `new-scene.tsx`, `split.tsx`, `insert-asset.tsx`, `object-mask/*`, `generations.ts`, `library.ts`, `inspect.ts` (`InspectEntry`), `hooks/use-document.ts` (`getRuntimeDocument`).
  - `apps/web/src/components/sidebar-right/inspector/*`: element components (`Animation`, `Effect`, `Stroke`, `Shadow`, `ColorStop`, `Scene`, `SolidPaint`, ...) and enum maps (`BLEND_MODES`, `TRANSITION_TYPES`, `EFFECT_TYPES`, `ANIMATION_TYPES`, `CAPTION_PRESETS`, `EASINGS`, `HORIZONTAL_CONSTRAINTS`, `VERTICAL_CONSTRAINTS`); `variables.tsx` (`InspectEntry`).
  - `apps/web/src/components/timeline/layers/keyframe.tsx` (`trackProperty`), `layers.tsx` (`Sequence`); `apps/web/src/components/genai/*` (`authoredElement`, `Audio`, `Captions`, `Rect`, `ImagePaint`, `VideoPaint`); `apps/web/src/components/canvas/draw-overlay.tsx`.
  - Compiled project bundles: import element components and runtime ops by name from `@diffusionstudio/jsx`, which `evaluate` binds to `JSX_RUNTIME` (compile config in [`apps/desktop/src`](../../../apps/desktop/src/README.md) `projects.ts`).
  - `packages/runtime/src/systems/playback.ts`: fires `Tickers` (the document's `advanceTicker`); `packages/encoder/src/encoder.ts` and `packages/runtime/src/systems/assets.ts` drain `FramePromises` that `hold` pushes.
