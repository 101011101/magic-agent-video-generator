# `packages/jsx/src`

The authoring surface of `@diffusionstudio/jsx`: the JSX element/prop types a project is written against, the pure helpers (`generate.*`, `transform.*`, `parseTime`, source-stamp constants), and the hook signatures (`useTicker`, `useResolution`, `__inspect`) that the editor's reconciler replaces at mount. No renderer lives here.

## Parts

| Part | Role |
|---|---|
| `index.ts` | Barrel. Re-exports every runtime value and type below. This is what `@diffusionstudio/jsx` resolves to (`exports["."]`). |
| `jsx-runtime.ts` | Type-only JSX runtime for `jsxImportSource: "@diffusionstudio/jsx"`. Declares `namespace JSX` with `Element = SolidJSX.Element` and `IntrinsicElements`: 30 camelCase composition tags (`stage`, `scene`, `group`, `rect`, `video`, `image`, `audio`, `text`, `textRange`, `sequence`, `captions`, `adjustmentLayer`, `solidPaint`, `linearGradientPaint`, `radialGradientPaint`, `imagePaint`, `videoPaint`, `colorStop`, `stroke`, `shadow`, `effect`, `mask`, `animation`, `keyframeTrack`, `keyframe`, `htmlPaint`, `html`, `shaderPaint`, `surfacePaint`, `surface`) each typed `XProps & SourceProps`, plus Solid's HTML/SVG tags for `<htmlPaint>` content. Drops DOM `canvas`/`audio`/`video`/`html`/`img`; re-adds `img` with `src?: AssetInput`. `rect`/`text`/`image` are unions of composition props and SVG props. Served as both `./jsx-runtime` and `./jsx-dev-runtime`. |
| `types.ts` | All element prop types and value unions. Value unions: `Time` (`number \| "${n}f" \| "MM:SS"`), `Fit`, `StrokeJoin`, `StrokeCap`, `HorizontalConstraint`, `VerticalConstraint`, `BlendMode`, `EffectType`, `Easing`, `AnimatableProperty`, `TransitionType`, `TransitionSpec`, `AnimationType`, `TextCase`, `CaptionPreset`, `CameraMatrix`, `TimelineView`. Shared prop groups (module-private): `IdentityProps` (`name`, `selected`, `clipHeight`, `expanded`), `PositionProps`, `OffsetProps`, `SizeProps`, `TransformProps`, `CompositeProps` (`blendMode`, `hidden`), `TimingProps` (`start`, `end`, `sourceIn`, `sourceOut`, `playbackRate`), `SequenceItemProps` (`transition`), `FillProps`, `MediaProps` (`src: string \| AssetRef`), `FitProps`, `FrameRateProps`, `AudioTrackProps` (`volume`, `muted`, `syncTo`), `ColorProps`, `FontProps`, `CommonProps`, `PaintProps`. Exported element props: `StageProps`, `SceneProps`, `GroupProps`, `AdjustmentLayerProps`, `RectProps`, `StrokeProps`, `ShadowProps`, `EffectProps`, `MaskProps`, `AnimationProps`, `KeyframeTrackProps`, `KeyframeProps`, `SolidPaintProps`, `GradientPaintProps`, `ColorStopProps`, `MediaPaintProps`, `VideoProps`, `ImageProps`, `HtmlPaintProps`, `HtmlProps`, `ShaderPaintProps`, `SurfacePaintProps`, `SurfaceProps`, `AudioProps`, `TextProps`, `TextRangeProps`, `SequenceProps`, `CaptionsProps`, `SourceProps` (`id`, `ref`). `SceneNode<E>` interface: `entity: koota.Entity`, `native`, `tag`, `props`, `parent`, `children`, `element: E \| null` (default `E` = host canvas). |
| `generate.ts` | Declarative assets. `generate.image/video/voice/audio(opts)` and `transform.upscale/removeBackground/addAudio(input)` validate args and return an `AssetRef` (class wrapping a `spec: AssetSpecInput`). Types: `AspectRatio`, `AssetInput` (`string \| AssetRef`), `Generate*Options`, `GenerateSpec`, `TransformSpec`, `TransformType`, `AssetSpecInput`. Helpers: `isAssetRef`, `getAssetSpec`, `getAssetInputs(spec)` (direct dependencies), `mapAssetInputs(ref, map)` (rebuild ref with mapped direct inputs), `isTransformType`, `isTransformSpec`. Wire form for the edit protocol: `SerializedAssetRef` (`{ $asset: SerializedAssetSpec }`), `serializeAssetRef(ref)` (recursive, drops `undefined`), `isSerializedAssetRef(value)`. |
| `time.ts` | `TIME_FPS = 30`. `parseTime(value): number \| undefined` converts `Time` to seconds: numbers pass through, `"30f"` divides by `TIME_FPS`, `"MM:SS"`/`"HH:MM:SS"` clock strings, negative allowed, unparsable returns `undefined`. |
| `source.ts` | Shared vocabulary for source stamping (compile step, host, editor all read it; none import each other). `ID_ATTR = "id"` (author-written, stripped at compile). `SOURCE_ATTR = "__source"` (compile step stamps `<file>:<id or document-order index>`). `LOOP_ATTR = "__loop"` (stamp for elements inside `<For>`/`<Index>`). `LOOP_TAGS = ["For","Index"]`, `isLoopTag`. `COMPOSITION_TAGS` (the 30 tags, kept in step with `jsx-runtime.ts` by hand), `CompositionTag`, `isCompositionTag(tag)` (accepts camelCase or PascalCase). `PropValue` (JSON-like), `isPropValue(value)` (rejects class instances such as `AssetRef`). `parseSource(id)` → `{ file, locator: number \| string }`, `formatSource(file, locator)`. |
| `hooks.ts` | Hook signatures that throw outside a mount via `hostOnly(name)`. `Ticker` type: `time`, `frame`, `delta`, `playing` accessors, `hold(promise)`. `useTicker(): Ticker` (timeline playhead per tick; `hold` delays export/capture frames until async work settles). `useResolution(): Accessor<number>` (device pixels per composition pixel, for `<surface>` bitmap sizing). |
| `inspect.ts` | The `@inspect` JSDoc annotation contract. `INSPECT_TAG = "inspect"`, `INSPECT_TYPES = ["number","color","text","font","boolean","select"]`, `InspectType`, `InspectValue` (`string \| number \| boolean`), `InspectDeclaration` (`file`, `name`, `type`, `path?`, `min?`, `max?`, `step?`, `options?`). `__inspect(declaration, initial): Accessor<InspectValue>` throws via `hostOnly`; the compile step injects calls to it, never authored by hand. |

## How it works

- A project sets `jsxImportSource: "@diffusionstudio/jsx"` in `tsconfig.json`. TypeScript resolves `<rect>`, `<scene>`, etc. through `jsx-runtime.ts` → `JSX.IntrinsicElements` → prop types in `types.ts`. This gives IntelliSense and `tsc --noEmit` checks.
- Project code calls `generate.image({ prompt })` or `transform.upscale(ref)` from `generate.ts`. Each call validates and returns an `AssetRef` value. The ref is passed as `src`, `startFrame`, `endFrame`, `refs`, or a transform input. Nesting order is dependency order; cycles are impossible because inputs are values, not ids.
- Nothing in this package runs a host. At mount, `packages/reconciler/src/runtime.ts` builds `JSX_RUNTIME = { ...authoring, ...elements, render, ..., useResolution, useTicker, __inspect }` and `packages/reconciler/src/evaluate.ts` binds the `@diffusionstudio/jsx` specifier to that object. The throwing `useTicker`, `useResolution`, `__inspect` from `hooks.ts`/`inspect.ts` are overwritten by live host-bound versions; the pure helpers and constants pass through unchanged.
- Source round-trip: the desktop compile step (`apps/desktop/src/source.ts`) uses `COMPOSITION_TAGS`/`isCompositionTag`/`isLoopTag` to find elements and `formatSource` to stamp `SOURCE_ATTR`/`LOOP_ATTR`. The reconciler (`packages/reconciler/src/document.ts`) reads those stamps onto entities. The editor hands the stamp back with a `PropValue` edit; `apps/desktop/src/edit.ts` uses `parseSource`/`isSerializedAssetRef` to write the change into the JSX.
- `AssetRef` is not a `PropValue`, so edits carry it as `SerializedAssetRef` (`serializeAssetRef` in `apps/web/src/engine/editor.ts`), and the source writer spells it back as the `generate.*`/`transform.*` call.
- `parseTime` is the single `Time` → seconds conversion used by the reconciler, `packages/dapi/src/time.ts`, and the web inspector.

## Interfaces

- Depends on:
  - `solid-js` (types only: `JSX`, `Accessor`) — peer dependency.
  - `koota` (type only: `Entity` in `SceneNode`).
  - No imports from other workspace packages.
- Used by:
  - [`packages/reconciler/src`](../../reconciler/src/README.md): `runtime.ts` spreads `* as authoring`; `elements.ts` imports every `*Props` type; `document.ts` uses `LOOP_ATTR`, `SOURCE_ATTR`, `parseTime`, `AnimatableProperty`, `AssetRef`; `renderer.ts` implements `Ticker`; `inspect.ts` implements `__inspect` against `InspectDeclaration`/`InspectValue`; `evaluate.ts` maps the `@diffusionstudio/jsx` specifier to `JSX_RUNTIME`.
  - [`packages/runtime/src`](../../runtime/src/README.md): `ai.ts` imports `generate`, `transform`, `Generate*Options`, `AssetInput`, `AssetRef`; `systems/assets.ts` uses `parseSource`; `traits/node.ts` and `traits/document.ts` import `AssetRef`, `SceneNode` types.
  - [`packages/dapi/src`](../../dapi/src/README.md): `time.ts` uses `parseTime`.
  - [`apps/desktop/src`](../../../apps/desktop/src/README.md): `source.ts` (compile step) uses `COMPOSITION_TAGS`, `ID_ATTR`, `INSPECT_TAG`, `INSPECT_TYPES`, `LOOP_ATTR`, `SOURCE_ATTR`, `formatSource`, `isCompositionTag`, `isLoopTag`, `InspectDeclaration`; `edit.ts` uses `parseSource`, `isSerializedAssetRef`, `isTransformType`, `PropValue`, `SerializedAssetRef`; `edit-types.ts` uses `InspectValue`, `PropValue`, `SerializedAssetRef`; `projects.ts` scaffolds new projects with `jsxImportSource: "@diffusionstudio/jsx"` and a dependency on this package.
  - [`apps/web/src`](../../../apps/web/src/README.md): `engine/editor.ts` (`isAssetRef`, `isPropValue`, `serializeAssetRef`, `SOURCE_ATTR`), `utils/gen-ai.ts` and `components/genai/*` (`generate`, `transform`, `getAssetSpec`, `isTransformSpec`, `mapAssetInputs`), `components/sidebar-right/inspector/*` (`AnimatableProperty`, `TransitionType`, `StrokeJoin`, `Fit`, `HorizontalConstraint`, `VerticalConstraint`, `Time`, `TIME_FPS`, `parseTime`, `InspectValue`).
  - `docs/examples/*.tsx` and `docs/reference/jsx/*.md`: the public authoring examples and reference for this surface.
- Build output: `tsc -p tsconfig.build.json` emits `dist/` from this dir; [../scripts/](../scripts/README.md) repoints `package.json` exports to `dist` on publish.
