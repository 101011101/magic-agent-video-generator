# `packages/sam2/src`

Browser runtime for SAM 2.1 video object segmentation: downloads and caches ONNX weights, runs them on WebGPU via ONNX Runtime, decodes frames with mediabunny, and tracks one object across a clip as per-frame logit masks.

## Parts

| Part | Role |
|---|---|
| `index.ts` | Public entry (`@diffusionstudio/sam2`). Re-exports `loadSam2`, `Sam2Video`, `holdFrame`, `trackObject`, `cachedSam2Models`, `DEFAULT_SAM2_MODEL`, `SAM2_MODELS`, `downloadSize`, `sam2Model`, `sam2ModelOfRepo`, `maskIsEmpty`, `paintMask`, `paintStroke`, and types `Sam2Model`, `Sam2ModelId`, `Sam2LoadOptions`, `Sam2Progress`, `Sam2Correction`, `Sam2Point`, `FrameRequest`, `TrackRequest`, `Sam2Mask`, `Sam2Stroke`. |
| `constants.ts` | Sub-path `@diffusionstudio/sam2/models`. `SAM2_MODELS`: catalogue of `tiny` (512px), `small`, `base-plus`, `large` (1024px), each with pinned Hugging Face `repo` URL and six `files` (`constants.json` + 5 `.onnx`) with byte sizes. `DEFAULT_SAM2_MODEL = 'tiny'`. Helpers `sam2Model(id)`, `sam2ModelOfRepo(repo)`, `downloadSize(model)`. Pipeline constants `HIDDEN_DIM=256`, `MEM_DIM=64`, `MEMORY_FRAMES=7`, `MAX_POINTERS=16`, `POINTER_TOKENS=4`, `DECODED_MASK_SIZE=256`. `geometryOf(imageSize)` → `Sam2Geometry` (`featSize=imageSize/16`, `maskSize=imageSize/4`, `memoryRows`, `memoryBlockBytes`). Type `ModelConstants` mirrors `constants.json`. |
| `load.ts` | `loadSam2(id?, {onProgress})` → `Promise<Sam2Video>`. One model per page (`loaded: Loading | null`): same id shares the promise and replays last progress; new id aborts an in-flight load (`AbortError`) and disposes the previous model before loading. `load()` checks `navigator.gpu`, calls `configureRuntime()`, `fetchModelFiles()`, validates `constants.json` against `model.imageSize` / `MEMORY_FRAMES`, builds five sessions in order (vision encoder and memory attention with `enableGraphCapture: true`), reads `pos_embed` via `readFloat16Initializer`, constructs `Sam2Video`. Releases built sessions on failure. Progress phases: `download {loaded,total}`, `compile`. |
| `weights.ts` | `fetchModelFiles(model, onProgress?, signal?)` → `ModelFiles` (`Record<ModelFileKey, ArrayBuffer>`). Cache in OPFS at `navigator.storage.getDirectory()/models/<org>--<repo>@<commit>/<path with / → -->`. `fetchStored` resumes partial files with HTTP `Range`, streams to disk via `createWritable`, verifies final size. Falls back to `fetchInMemory` when OPFS is unavailable or throws a storage `DOMException` (`isStorageError`). `retain(root)` deletes stale revisions of the same repos. `cachedSam2Models()` → `Set<Sam2ModelId>` of models whose every file is present at catalogue size. |
| `onnx.ts` | `readFloat16Initializer(model: ArrayBuffer, name)` → `Float32Array`. Minimal protobuf walker (`fields()` generator over field numbers `ModelProto.graph=7`, `GraphProto.initializer=5`, `TensorProto.{data_type=2,name=8,raw_data=9}`) plus `halfToFloat`. Used to pull the vision encoder's folded `pos_embed` constant, which a captured graph does not emit. |
| `sessions.ts` | Thin `onnxruntime-web/webgpu` wrapper. `configureRuntime()` sets `ort.env.wasm.wasmPaths` to the bundled `ort-wasm-simd-threaded.asyncify.wasm?url` and `powerPreference='high-performance'`. `runtimeDevice()` → the runtime's `GPUDevice`. `createSession(model, gpuOutputs, options)` with `executionProviders: [{name:'webgpu'}]`, `preferredOutputLocation: 'gpu-buffer'` for listed outputs. Tensor helpers `gpuTensor`, `floatTensor`, `intTensor`; readers `floats`, `gpuBuffer`; `disposeOutputs`. Types `Session`, `Tensor`, `Outputs`. |
| `env.d.ts` | Declares `*.wasm?url` module (Vite asset import). |
| `gpu.ts` | WebGPU compute helpers sharing the runtime's device. `createStorageBuffer(device, size, label)`. `FramePreprocessor`: uploads a `VideoFrame` into an `rgba8unorm` texture (`copyExternalImageToTexture`), runs `preprocessShader` to write planar normalized RGB into `pixels` (`[1,3,S,S]` float32). Params: frame size, `rotation/90`, box-filter `taps` (≤ `MAX_TAPS=8`), mean, std. `TokenTransposer`: runs `transposeShader` to turn `[1,C,H,W]` `feats2` into `[H*W,1,C]` tokens. Type `Rotation = 0|90|180|270`. |
| `shaders.ts` | WGSL sources. `preprocessShader(imageSize)`: resize to square, apply rotation (`toSource`), multi-tap box filter, `(rgb - mean)/std`, planar write. `transposeShader(featTokens)`: `tokens[t*C+c] = channels[c*T+t]`. `WORKGROUP_SIZE = 16`. |
| `memory.ts` | `MemoryBank`: GPU-resident memory for memory attention. Owns `memory` and `memoryPos` storage buffers of `memoryRows` rows. `setPositions(spatial)` builds one `memory_pos` buffer per temporal slot (spatial + `memory_temporal_positional_encoding[slot]`). `condition(index, tokens, pointer)` sets the prompted frame; `push(...)` appends a tracked frame (keeps ≤ `MAX_POINTERS-1` recent); `rewind()` drops tracked frames, keeps seed; `reset()` clears all. `assemble(index, totalFrames)` copies slot 0 = prompted frame, slots 1..6 = newest tracked first (empty slots repeat), 16 pointers, and returns normalized frame distances for `pointer_tpos`. `setPointerPositions(buf)` writes pointer temporal rows. Buffers pooled via `retain`. |
| `tracker.ts` | `Sam2Video`: the inference pipeline over one object. Constructor takes `Sam2Model`, `GPUDevice`, `Sam2Sessions` (five sessions), `ModelConstants`, `pos_embed`. Methods: `seed(frame, rotation, points, index, correct?)`, `hold(frame, rotation)`, `holding`, `release()`, `preview(points)`, `seedHeld(points, index, correct?)`, `track(frame, rotation, index, totalFrames)`, `rewind()`, `reset()`, `dispose()`, `maskSize`, `geometry`, `model`. Private `encode` (preprocess + vision encoder), `segment` (mask decoder, then `remember` when prompted or `isReliable`), `remember` (memory encoder → bank), `unpack` (→ `packMask`). Constants `RELIABLE_IOU=0.25` (remember tracked frame), `PLAUSIBLE_IOU=0.15` (else return `clearMask`). `maskLogits` bilinear-upsamples a corrected mask to `high_res_mask`. Types `Sam2Point {x,y,label: 0|1|2|3}`, `Sam2Correction = (mask) => mask`, `Sam2Sessions`. |
| `video.ts` | Frame supply from mediabunny. `holdFrame(model, {track, timestamp})`: decodes one sample via `VideoSampleSink.getSample`, calls `model.hold`. `trackObject(model, {track, timestamps, seedIndex, points, correct?, signal?, onMask})`: seeds at `timestamps[seedIndex]`, then walks forward with `samplesAtTimestamps` (next decode overlaps inference), then `model.rewind()` and walks backward in batches of `REVERSE_BATCH=12` decoded in file order. Frames with an unchanged `sample.timestamp` reuse the previous mask. Calls `onMask(index, mask)` per frame. `withVideoFrame` closes `VideoFrame` and `VideoSample`. Types `FrameRequest`, `TrackRequest`. |
| `mask.ts` | Sub-path `@diffusionstudio/sam2/mask`. Type `Sam2Mask {logits: Float32Array, size, score, iou}` (logits on the model's `maskSize` grid, object where `> 0`). `GIVEN_LOGIT = 10`. `packMask(decoded, size, score, iou)`: exact inverse of the decoder's 2x bilinear upsample (tridiagonal Thomas solve, `downsample`) when `size*2 === 256`. `clearMask`, `maskIsEmpty`. Brush: type `Sam2Stroke {label: 0|1, radius, points}`; `paintMask(mask, strokes, aspect)` (copy) and `paintStroke(mask, stroke, aspect, from=0)` (in place) paint capsule segments with slope `BRUSH_SLOPE=4` clamped to `±GIVEN_LOGIT`. |

## How it works

- Load: `loadSam2(id)` → `fetchModelFiles` (OPFS cache or HF fetch, resumable) → `createSession` x5 on WebGPU → `readFloat16Initializer(visionEncoder, 'pos_embed')` → `new Sam2Video(...)`.
- All intermediate tensors stay on the GPU: sessions are created with `preferredOutputLocation: 'gpu-buffer'`, and `FramePreprocessor`, `TokenTransposer`, `MemoryBank` use `runtimeDevice()` so buffers are passed by handle (`gpuTensor`).
- Seed frame: `Sam2Video.seed` → `encode` (preprocess shader → vision encoder) → mask decoder on `feats2_no_mem` with user points → `packMask` → optional `correct` callback → memory encoder with `binarize=1` → `bank.condition`.
- Interactive prompting: `holdFrame` → `Sam2Video.hold` keeps encoder outputs; `preview(points)` and `seedHeld` run only the mask decoder. The encoder is graph-captured, so encoding any frame overwrites the held outputs.
- Tracked frame: `Sam2Video.track` → `encode` → `TokenTransposer` (feats2 → tokens) → `bank.assemble` (copy 7 memory blocks + 16 pointers, return distances) → `pointerTpos` → `bank.setPointerPositions` → memory attention → mask decoder with `paddingPrompt` (label `-1`) → `packMask`. Frame is remembered only when `score > 0 && iou >= 0.25`; reported empty when `iou < 0.15`.
- Clip traversal: `trackObject` runs seed, forward pass, `rewind()`, backward pass; emits every mask through `onMask` and respects `signal`.
- Mask corrections: caller paints `Sam2Stroke`s over a `Sam2Mask` with `paintMask`; a `Sam2Correction` applied at seed time turns the corrected mask into a mask prompt (`score = ±GIVEN_LOGIT`, `maskLogits` upsample) for the memory encoder.
- Model switch: `loadSam2` with a different id aborts the current download/compile, disposes the old `Sam2Video` (sessions, buffers, bank), then loads the new one.

## Interfaces

- Depends on:
  - `onnxruntime-web/webgpu` and its `ort-wasm-simd-threaded.asyncify.wasm` (`sessions.ts`).
  - `mediabunny` (`VideoSampleSink`, `InputVideoTrack`, `VideoSample`) (`video.ts`).
  - Browser APIs: WebGPU (`navigator.gpu`, `GPUDevice`), OPFS (`navigator.storage.getDirectory`), `fetch` with `Range`, `VideoFrame`, `TextDecoder`.
  - Model files produced by [`../scripts/README.md`](../scripts/README.md) and hosted at the `repo` URLs in `constants.ts`.
  - `@webgpu/types` (dev), `tsconfig` extends `../../tsconfig.base.json` with `lib: es2024, DOM, DOM.Iterable`.
- Used by (`apps/web`, dependency `"@diffusionstudio/sam2": "*"`):
  - `apps/web/src/engine/object-mask/tracking.ts`: dynamic-imports `loadSam2`, `trackObject`, `holdFrame`; calls `Sam2Video.reset`, `seedHeld`, `preview`, `release`, `holding`, `maskSize`, `model.repo`; imports `paintMask` from `/mask`, `sam2ModelOfRepo` from `/models`; types `Sam2Point`, `Sam2Video`, `Sam2Mask`, `Sam2Model`, `Sam2ModelId`.
  - `apps/web/src/engine/object-mask/brush.ts`: `paintMask`, `paintStroke`.
  - `apps/web/src/engine/object-mask/commit.tsx`, `overlay.ts`: `geometryOf`; type `Sam2Mask`.
  - `apps/web/src/engine/object-mask/store.ts`: `DEFAULT_SAM2_MODEL`, `SAM2_MODELS`; types `Sam2Mask`, `Sam2Model`, `Sam2ModelId`.
  - `apps/web/src/engine/object-mask/frame.ts`: type `Sam2Mask`.
  - `apps/web/src/components/canvas/object-mask-bar.tsx`: `SAM2_MODELS`, `downloadSize`, `sam2Model`, `cachedSam2Models`.
  - `apps/web/src/dapi/handlers/media-segment.ts`: type `Sam2Point`.
- Package exports (`packages/sam2/package.json`): `.` → `src/index.ts`, `./mask` → `src/mask.ts`, `./models` → `src/constants.ts`. No build step; consumed as TypeScript source. `sideEffects: false`.
