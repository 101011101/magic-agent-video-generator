# README tree

Index of every README in the tree, with its one-line purpose.

- [(root)](README.md) — Diffusion Studio: an agent-first video editor where a project is SolidJS/JSX source code, the app renders that code to an editable canvas, and agents drive the app through an MCP server and a `diffusion` CLI.
  - [.github/](.github/README.md) — GitHub Actions CI: builds and signs the desktop installers into a draft GitHub release on a version tag, and updates the Homebrew cask after the release is published.
    - [workflows/](.github/workflows/README.md) — GitHub Actions that build, sign, notarize, and publish the desktop app installers, then update the Homebrew cask.
  - [apps/](apps/README.md) — The three deliverables of the Diffusion Studio editor: the editor UI (web), the Electron shell that hosts it and serves the agent-facing MCP server (desktop), and the `diffusion` command-line client that talks to that server (cli).
    - [cli/](apps/cli/README.md) — `@diffusionstudio/cli`: the `diffusion` command (alias `dapi`), a Node binary that turns each shell command into one MCP tool call against the running Diffusion Studio desktop app, and that proxies stdio MCP to the app for agents that cannot connect by URL.
      - [scripts/](apps/cli/scripts/README.md) — Developer tooling that puts the locally built `diffusion` / `dapi` CLI on the PATH, so a dev build of the desktop app and a shell can run the workspace's `dist/index.js`.
      - [src/](apps/cli/src/README.md) — Source of the `diffusion` / `dapi` command-line binary: a thin MCP client that turns shell commands into tool calls against the running Diffusion Studio desktop app.
    - [desktop/](apps/desktop/README.md) — `@diffusionstudio/desktop`: the Electron shell that turns the web editor into the installable Diffusion Studio app. It owns the window, project folders on disk, TSX compilation, the source-edit writer, the MCP server agents connect to, the in-app agent-chat host, and CLI/MCP registration on the user's machine.
      - [scripts/](apps/desktop/scripts/README.md) — Build-time helper scripts for the Electron app: compile the macOS native addon, stage app resources (CLI, runtime deps, docs) for electron-forge, and regenerate platform icons/installer art.
      - [src/](apps/desktop/src/README.md) — Electron main process and preload of the Diffusion Studio desktop app: window and IPC, project folders on disk (scaffold, compile, write-back, watch), the MCP server agents connect to, the agent-chat host process, and CLI/MCP registration on the user's machine.
        - [dapi/](apps/desktop/src/dapi/README.md) — The desktop app's MCP server: serves the `packages/dapi` tool catalog over Streamable HTTP on loopback so agents and the `diffusion` CLI can drive the editor.
          - [handlers/](apps/desktop/src/dapi/handlers/README.md) — Implements the two MCP tools that must run in the Electron main process (`logs`, `report`) and exports them as one `mainHandlers` map for the dapi server.
        - [native/](apps/desktop/src/native/README.md) — macOS-only Node-API addon that gives the Electron `BrowserWindow` a custom corner radius and a custom blurred backdrop while keeping the standard window (traffic lights, OS shadow, vibrancy, live resize).
    - [web/](apps/web/README.md) — `@diffusionstudio/web`: the Diffusion Studio editor UI. A SolidJS + Vite single-page app that mounts a compiled JSX project into a koota runtime world, draws it on a canvas and timeline, writes canvas edits back to the project source, and serves renderer-side agent tools. Runs inside the Electron window (`apps/desktop`) or as a hosted browser app on Vercel.
      - [public/](apps/web/public/README.md) — Static files Vite copies verbatim to the web build root (`/`): brand marks, social preview image, and two browser-to-desktop deep-link bridge pages.
      - [src/](apps/web/src/README.md) — All application code of the Diffusion Studio editor UI: boot, routing, global providers, and the subsystems that open a JSX project, edit it on a canvas and timeline, export it, and serve agent tools.
        - [agent-chat/](apps/web/src/agent-chat/README.md) — The editor's agent chat UI: a SolidJS panel in the left sidebar that drives the user's Claude Code or Codex against the open project through the `@diffusionstudio/agent-chat` host.
        - [assets/](apps/web/src/assets/README.md) — Static media bundled into the editor UI: the SVG icon set, the two UI typefaces, and PNG images. No code lives here; every file is consumed by Vite at build time.
          - [images/](apps/web/src/assets/images/README.md) — Bundled PNG images that UI code imports by URL: the desktop-app promo banner, AI voice picker avatars, and two unused placeholder frames.
        - [components/](apps/web/src/components/README.md) — All SolidJS view code of the editor UI: the editor surfaces (canvas, timeline, left and right sidebars, gen-AI prompt box), the dashboard views, the shared `ui/` widget kit, and app-wide overlays (upgrade dialog, purchase success, environment guards, context menu).
          - [assets/](apps/web/src/components/assets/README.md) — Solid primitive that truncates a long asset file name in the middle and expands it on demand.
          - [canvas/](apps/web/src/components/canvas/README.md) — The editor's center stage: the rendered scene viewport plus the overlays that create elements, accept drops, pick tools, and drive the object-mask and clip-path tools.
          - [dashboard/](apps/web/src/components/dashboard/README.md) — SolidJS views and widgets for the Diffusion Studio dashboard: the landing screen that lists projects, starts agent chats, and manages account, billing, credits, agents (MCP/CLI), settings, and help.
          - [genai/](apps/web/src/components/genai/README.md) — Prompt box and selection action bar that turn a user prompt into declarative `generate.*` / `transform.*` sources and insert them on the canvas.
          - [sidebar-left/](apps/web/src/components/sidebar-left/README.md) — Builds the editor's left sidebar: project header (menu + rename), and the Assets panel (folder browser, import, drag-drop, per-item context menus) or the agent chat panel, chosen by tab.
            - [project-menu/](apps/web/src/components/sidebar-left/project-menu/README.md) — Builds the editor's main application menu: the logo dropdown in the left sidebar with File / Edit / View / Tool / AI credits / Help submenus.
          - [sidebar-right/](apps/web/src/components/sidebar-right/README.md) — Right-hand editor controls: the Inspector (property panels for the current selection) and the Soundboard (audio mixer strip). Both read the ECS world and write edits back through `DocumentEditor`.
            - [inspector/](apps/web/src/components/sidebar-right/inspector/README.md) — The right-sidebar Inspector: a stack of property panels that reads the current selection (nodes, keyframes, or a library asset) from the ECS world and writes edits back through `DocumentEditor`, so the JSX file, undo history, and canvas stay in sync.
              - [transform/](apps/web/src/components/sidebar-right/inspector/transform/README.md) — The "Transform" inspector section: position plus opt-in rows for constraints, rotate, anchor, offset, scale and skew on the selected node.
            - [soundboard/](apps/web/src/components/sidebar-right/soundboard/README.md) — Three-channel mixer strip: two selectable layer meters plus a master meter, each with a dB fader, live RMS/peak bars and a dB scale.
          - [timeline/](apps/web/src/components/timeline/README.md) — The editor's bottom timeline: a `<canvas>` the timeline engine draws clips on, plus the DOM row column (`Layers`) on its left, plus the time display formatter both share.
            - [layers/](apps/web/src/components/timeline/layers/README.md) — The DOM row column on the left of the timeline: one labelled row per clip, sub-item and keyframe track of the active scene, plus the transport header and Figma-style drag-to-reparent.
          - [ui/](apps/web/src/components/ui/README.md) — Shared SolidJS widget kit for the web editor: shadcn-solid style wrappers over Kobalte primitives plus editor-specific controls (color, keyframe, slider-input, fill row, floating inspector).
        - [context/](apps/web/src/context/README.md) — SolidJS context providers that hold editor-wide state (auth session, open project, timeline controller, export, prompt-input dialog, panel layout) and one shared render path (`renderScene`) used by both the UI export and the agent export tool.
        - [dapi/](apps/web/src/dapi/README.md) — Renderer side of the Diffusion Studio agent tool API (DAPI): receives tool calls from the desktop MCP server over IPC, runs them against the open editor world, and replies.
          - [handlers/](apps/web/src/dapi/handlers/README.md) — One handler per renderer-side agent tool: each takes parsed tool args plus a `ToolContext` and returns the tool's typed result for the desktop MCP server.
          - [lib/](apps/web/src/dapi/lib/README.md) — Shared helpers that DAPI tool handlers call to resolve targets (assets, nodes, scenes), pick and lay out video frames, and decode preview bytes.
        - [engine/](apps/web/src/engine/README.md) — The editor engine: owns the koota `RuntimeWorld` of an open project, runs the per-frame loop (runtime systems + editor input/HUD/timeline systems), and turns every user command into a document change that is reported back as an `EntityEdit` for the JSX source.
          - [hooks/](apps/web/src/engine/hooks/README.md) — Solid hooks that give UI components reactive reads (and a few writes) of editor state on the koota world, so panels never import the Engine object.
          - [hud/](apps/web/src/engine/hud/README.md) — Paints the editor chrome over the rendered stage canvas (node headers, selection box with handles, hover outlines, snap guides, marquee, size readout) and registers the hit regions those overlays respond to.
          - [input/](apps/web/src/engine/input/README.md) — Turns queued pointer events and keyboard state into document edits: hit-testing, drag/hover dispatch, select/move/resize/rotate/marquee gestures with snapping, keyboard shortcuts, and the stage cursor.
          - [object-mask/](apps/web/src/engine/object-mask/README.md) — The Object Mask tool: click or brush an object on a video clip, segment and track it with SAM2 in the browser, and write the result into the library as a `.mask` file plus a `<mask>` element on the clip.
          - [timeline/](apps/web/src/engine/timeline/README.md) — The editor's timeline engine: a per-frame immediate-mode canvas pass that draws the active scene's clips against time and turns pointer gestures on that canvas (select, move, trim, scrub, marquee, zoom, scroll) into document edits.
            - [render/](apps/web/src/engine/timeline/render/README.md) — Immediate-mode canvas draw functions for the timeline: each function paints one layer (ruler, rows, clips, playhead, work area, marquee, snap line) and handles the pointer gestures that belong to that rectangle.
        - [hooks/](apps/web/src/hooks/README.md) — Reusable SolidJS hooks: small reactive primitives (signals + cleanup) that wrap browser, desktop-IPC, audio, pointer, and router state for the editor UI.
        - [lib/](apps/web/src/lib/README.md) — Framework-free infrastructure modules for the editor UI: the renderer-to-main IPC bridge and its desktop-only wrappers, cloud clients (Supabase auth, tRPC API, uploads, checkout), local persistence (IndexedDB, `localStorage` store), analytics, and small Solid/Tailwind helpers.
          - [store/](apps/web/src/lib/store/README.md) — Namespaced key-value persistence over `localStorage`, exposed to Solid components as reactive signals for UI preferences.
        - [pages/](apps/web/src/pages/README.md) — Route-level Solid components: one page per URL the app router serves (login, dashboard, project editor, auth callback, 404).
        - [projects/](apps/web/src/projects/README.md) — Renderer-side project service: the web app's typed client for the Electron main process's project folders (list, open, create, compile, write edits, watch, filesystem), plus the IndexedDB project records.
        - [types/](apps/web/src/types/README.md) — Small shared type module for the web app: aspect-ratio and model-output string unions, drag-and-drop `DataTransfer` type keys, and an `Optional<T, K>` helper.
        - [utils/](apps/web/src/utils/README.md) — Framework-free helper functions for the web editor (assert/clamp, browser file and color APIs, color math, display formatters, Solid signal helpers) plus `gen-ai.ts`, the editor's concrete `GenAi` service that turns `generate.*`/`transform.*` declarations into library assets through the tRPC backend.
  - [assets/](assets/README.md) — Brand media embedded in the repo's top-level `README.md`; no code. Pure asset folder: the root README should carry it as one row.
  - [docs/](docs/README.md) — The agent-facing manual: skills, JSX and tool reference, guides, runnable examples, and a house-style brand kit, shipped inside the desktop app and handed to every MCP client on connect.
    - [brand/](docs/brand/README.md) — Fallback house style for agents: four reference pages (design, voice, video, library) plus bundled JSX components and compositions that apply them. Used only when the brief, project, or user supplies no style of their own.
      - [assets/](docs/brand/assets/README.md) — The house-style brand kit: reusable JSX components, starter compositions, and empty asset folders that agents copy into a project when no other branding is specified.
    - [examples/](docs/examples/README.md) — Eleven self-contained project entry files that show the `@diffusionstudio/jsx` composition API, from a basic cut to raw WebGPU on a `<surface>`. Copy one into a project folder as `index.tsx` and run `diffusion open <folder>`.
    - [guides/](docs/guides/README.md) — Task know-how for agents: one motion reference (easings), one prompt-pattern page (`media_listen`), and two end-to-end editing walkthroughs (podcast clip, talking head). Linked from `docs/skills/editor.md` and `docs/skills/watch.md`.
      - [motion/](docs/guides/motion/README.md) — Motion guidance: which easing curve to use for each kind of move, and the pixel-snapping limit that makes slow moves stutter.
      - [prompts/](docs/guides/prompts/README.md) — Prompt-writing guidance for the AI-backed media tools; today it covers only `media_listen`.
      - [walkthroughs/](docs/guides/walkthroughs/README.md) — Worked end-to-end editing examples: each shows the full brief → analysis → JSX → verification → captions path for one common video job.
    - [reference/](docs/reference/README.md) — The authoritative API for agents: `jsx/` documents the project markup the app compiles and mounts; `tools/` documents every tool as served over MCP and the `diffusion` CLI. No `README.md` at this level in source; each subdir has its own index.
      - [jsx/](docs/reference/jsx/README.md) — Authoritative reference for the JSX composition language: the camelCase elements, props, timing, paints, generation and lifecycle a project's `index.tsx` is written in.
      - [tools/](docs/reference/tools/README.md) — Reference for the 18 agent tools: the surface contract (MCP + `diffusion` CLI, names, results, errors, shared types) in `README.md`, plus one page per tool with its fields, output shape, and failure cases.
        - [media/](docs/reference/tools/media/README.md) — Reference pages for the seven `media_*` tools: one page per tool that inspects a media file by path (probe, frames, filmstrip, waveform, transcript, semantic listen, object mask) over MCP or the `diffusion media` CLI.
    - [skills/](docs/skills/README.md) — Skill pages: the operating procedures an agent reads on connect and follows for the whole session when it drives Diffusion Studio over MCP.
  - [packages/](packages/README.md) — Shared npm workspace libraries (`@diffusionstudio/*`) that build the editor engine: authoring vocabulary, ECS runtime, JSX-to-entity reconciler, asset library, encoder, agent tool catalog, agent chat host, and ML segmentation. The apps in `apps/` compose these into the desktop app, web editor, and CLI.
    - [agent-chat/](packages/agent-chat/README.md) — `@diffusionstudio/agent-chat`: the editor's in-app agent chat. A Node host runs the user's own Claude Code or Codex CLI against a project and streams the conversation over a WebSocket. A browser-safe protocol, client, and reducer let the UI render it as a view over host state.
      - [src/](packages/agent-chat/src/README.md) — Source of `@diffusionstudio/agent-chat`: a browser-safe wire protocol, client, and reducer (root), plus the Node agent host (`host/`) and its program wrapper (`bin.ts`).
        - [host/](packages/agent-chat/src/host/README.md) — Node-side agent host: runs the user's own Claude Code or Codex CLI against a project, persists each chat as an event log, and serves it to the editor UI over a token-guarded loopback WebSocket.
      - [test/](packages/agent-chat/test/README.md) — Vitest suite for the agent-chat package: unit tests for the reducer, store and harness helpers, plus an end-to-end loop over a real WebSocket with the fake harness.
    - [assets/](packages/assets/README.md) — `@diffusionstudio/assets`: a project's asset library. Reads and writes the `assets.yml` manifest, gives each media file a content-hash id, probes media metadata, resolves JSX `src` strings to `Asset` records, and derives cached thumbnails and waveforms. Host-agnostic: all file access goes through a `ProjectFS` the app supplies.
      - [src/](packages/assets/src/README.md) — All code of `@diffusionstudio/assets`: the asset data model, the `assets.yml` manifest codec, content ids, media probing, the stateful `AssetLibrary`, the `cache/` store with its derivations, and the `.mask` file format.
        - [derive/](packages/assets/src/derive/README.md) — Pure derivation functions: a media `Blob` in, a thumbnail (WebP) or an audio waveform (bytes) out. No cache, no state.
    - [dapi/](packages/dapi/README.md) — `@diffusionstudio/dapi`: the single tool catalog the Diffusion Studio app exposes to agents. Each tool is a name, description, and zod input/output schemas. The desktop app serves it over MCP, the CLI derives commands from it, the web renderer validates against it.
      - [src/](packages/dapi/src/README.md) — Source of `@diffusionstudio/dapi`: the typed agent tool catalog plus the shared contract (tool shape, time parsing, errors, MCP address, JSON Schema export, IPC wire) that the desktop server, web renderer, and CLI import. Definitions only; no handlers.
        - [tools/](packages/dapi/src/tools/README.md) — One file per dapi tool: the name, title, agent-facing description, and zod `input` / `output` / `result` schemas that the app serves over MCP, the CLI derives commands from, and the renderer validates against. Definitions only; no handler code lives here.
    - [encoder/](packages/encoder/README.md) — `@diffusionstudio/encoder`: offline export of a runtime capture world. Steps the runtime systems frame by frame, draws into the world's canvas, renders audio through an `OfflineAudioContext`, and muxes both with mediabunny into mp4/webm/mov/ogg. Also renders single frames to PNG and composes labelled contact sheets for agents.
      - [src/](packages/encoder/src/README.md) — Offline encoder: steps a prepared "capture world" frame by frame through the runtime systems and writes the result as a video/audio file (mediabunny), standalone PNG frames, or a labelled contact sheet.
    - [jsx/](packages/jsx/README.md) — `@diffusionstudio/jsx`: the authoring surface a project's TSX is written against. Element types, pure helpers (`generate.*`, `transform.*`, `parseTime`, source-stamp constants), and hook signatures the editor replaces at mount. No renderer; published to npm.
      - [scripts/](packages/jsx/scripts/README.md) — npm lifecycle hooks that swap `package.json` `exports` from `src/*.ts` to `dist/*.js` for the published tarball, then restore them.
      - [src/](packages/jsx/src/README.md) — The authoring surface of `@diffusionstudio/jsx`: the JSX element/prop types a project is written against, the pure helpers (`generate.*`, `transform.*`, `parseTime`, source-stamp constants), and the hook signatures (`useTicker`, `useResolution`, `__inspect`) that the editor's reconciler replaces at mount. No renderer lives here.
    - [koota-solid/](packages/koota-solid/README.md) — `@diffusionstudio/koota-solid`: Solid bindings for the koota ECS, a port of `@koota/react`. Lets `apps/web` components subscribe to entities, traits, relations, and queries in the runtime world. Every hook returns an `Accessor`.
      - [src/](packages/koota-solid/src/README.md) — All source of `@diffusionstudio/koota-solid`: Solid hooks and a context provider that expose koota ECS world state to editor components as `Accessor` signals.
        - [hooks/](packages/koota-solid/src/hooks/README.md) — Solid hooks that turn koota ECS world state (queries, traits, tags, relations) into Solid `Accessor` signals so editor components re-render when entity data changes.
        - [utils/](packages/koota-solid/src/utils/README.md) — Small helpers that let the hooks in [../hooks/](../hooks/README.md) accept either plain values or Solid accessors, and tell koota traits/pairs/worlds apart from functions.
        - [world/](packages/koota-solid/src/world/README.md) — Solid context that carries one koota `World` down the component tree so every hook can find the ECS world without prop drilling.
    - [reconciler/](packages/reconciler/README.md) — `@diffusionstudio/reconciler`: evaluates a compiled project bundle, binds it to Solid's universal renderer, and reconciles the element tree onto koota entities in a `@diffusionstudio/runtime` world. `mount(code, world)` turns `jsx` vocabulary into `runtime` state and keeps it live.
      - [src/](packages/reconciler/src/README.md) — Evaluates a compiled project bundle, binds it to Solid's universal renderer, and reconciles its JSX element tree onto `@diffusionstudio/runtime` ECS entities (koota) in one world.
    - [runtime/](packages/runtime/README.md) — `@diffusionstudio/runtime`: the headless editor engine. A koota ECS world holds the composition as entities with traits; five deterministic systems turn that world into a drawn frame and scheduled audio on host-injected surfaces. No DOM dependency, no solid-js.
      - [src/](packages/runtime/src/README.md) — All source of `@diffusionstudio/runtime`: the headless koota ECS editor engine (data model, world, write/read paths, per-frame systems, media decoders, helpers).
        - [actions/](packages/runtime/src/actions/README.md) — Write path of the runtime: plain `(world, ...)` functions that mutate the koota ECS world (entities, hierarchy, time, size, camera, playback, keyframes, clipboard). No undo or persistence here; the app observes koota add/remove/change events on the traits these functions touch.
        - [fonts/](packages/runtime/src/fonts/README.md) — Web font catalog and loader: registers a font in the world's `Fonts` trait and in the environment's `FontFaceSet` so text layout and rasterization use it.
        - [math/](packages/runtime/src/math/README.md) — Pure 2D affine math: matrices, bounding boxes, and quad geometry used by the transform system, hit testing, camera, and canvas interactions.
        - [media/](packages/runtime/src/media/README.md) — Lazy, per-entity media decoders and the audio graph: turns an entity's `AssetId` into a bitmap (video, image, sequence, mask, shader, waveform), scheduled Web Audio buffers, or caption text for the systems to draw; plus offline helpers (filmstrip, waveform, transcode, audio sync).
          - [caption/](packages/runtime/src/media/caption/README.md) — Turns a transcript asset into timed, styled caption text on a `<captions>` entity: seven preset "decoders" that group words, place the caption box, write the current phrase per playhead frame, and draw it.
        - [queries/](packages/runtime/src/queries/README.md) — Read-only lookups over the ECS world: entity classification, tree walks, camera/coordinate mapping, hit tests, selection geometry, and the timeline layer index. No function here mutates the world; writes live in `../actions`.
        - [systems/](packages/runtime/src/systems/README.md) — The deterministic per-frame pipeline: resolve assets, advance time, sample motion, compute transforms, draw the frame. Same code runs in the editor (`apps/web`) and the offline encoder (`packages/encoder`). Browser-only systems (input, keyboard, hud, timeline) stay in `apps/web/src/engine`.
        - [traits/](packages/runtime/src/traits/README.md) — Defines every ECS trait (component) and the one relation that make up a Diffusion Studio runtime world: the data schema that systems, actions, queries, and the serializer all read and write.
        - [utils/](packages/runtime/src/utils/README.md) — Pure, DOM-free helper functions the headless runtime shares across its actions, systems, and media code: color packing, time/frame math, text layout and canvas text rendering, stroke/surface canvas helpers, transition windows, sort comparators, and generation-pulse colors.
        - [world/](packages/runtime/src/world/README.md) — Creates the koota ECS world for one project, wires the runtime invariants as trait observers, gives hot paths raw SoA store access, and clones entity subtrees through plain-object records.
    - [sam2/](packages/sam2/README.md) — `@diffusionstudio/sam2`: SAM 2.1 video object segmentation and tracking in the browser. Loads five fixed-shape ONNX graphs on ONNX Runtime WebGPU, decodes frames with mediabunny, and returns one logit mask per frame. Weights come from pinned Hugging Face repos and are cached in OPFS.
      - [scripts/](packages/sam2/scripts/README.md) — Offline Python exporter that turns a SAM 2.1 checkpoint into the five fixed-shape fp16 ONNX graphs plus `constants.json` that `packages/sam2/src` loads in the browser.
      - [src/](packages/sam2/src/README.md) — Browser runtime for SAM 2.1 video object segmentation: downloads and caches ONNX weights, runs them on WebGPU via ONNX Runtime, decodes frames with mediabunny, and tracks one object across a clip as per-frame logit masks.
  - [patches/](patches/README.md) — `patch-package` diffs applied to `node_modules` after every `npm install`; currently one fix to the `koota` ECS query engine.
  - [scripts/](scripts/README.md) — Repo-level Node scripts for developing the desktop app from source and cutting a release.
    - [lib/](scripts/lib/README.md) — Shared helper for repo maintenance scripts: a cross-platform way to run `npm` from Node.
