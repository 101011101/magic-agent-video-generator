# `apps/web/src/engine/timeline`

The editor's timeline engine: a per-frame immediate-mode canvas pass that draws the active scene's clips against time and turns pointer gestures on that canvas (select, move, trim, scrub, marquee, zoom, scroll) into document edits.

## Parts

| Part | Role |
|---|---|
| [render/](render/README.md) | Draw functions, one per layer: `renderLayers` (rows and clips, thumbnails, waveforms, captions, groups, keyframes), `renderRuler`, `renderPlayhead`, `renderWorkarea`, `updateMarquee`/`renderMarquee`, `renderSnapLine`. Each function hit-tests the rectangle it draws in the same frame. |
| `timeline.ts` | `timelineSystem(world)`: the per-frame pass. Reads `TimelineSurface`, resolves the scene (`getTimelineScene`), calls `updateTimelineTransform`, clears the canvas, scales by `devicePixelRatio`, runs `updateDragGestures`, then the `render/` functions in fixed order, sets the cursor, and calls `pointer.reset()`. `clearTimeline` wipes the canvas and pointer regions when no scene is active. |
| `controller.ts` | `createTimelineController(world)`: the DOM side. `attachCanvas`/`detachCanvas` bind `#timeline-canvas`, a `ResizeObserver`, `wheel` and `pointerdown`. `mount`/`unmount` bind `[data-timeline-layers]` (DOM row labels) and body `pointermove`/`pointerup`. `handleWheel`: ctrl/meta = zoom around the pointer (clamped to `TIMELINE_RESOLUTION_RANGE`), else scroll X or Y by the larger delta. `scroll` (label column wheel), `scrollBy`, `clientToFrame`, `clientToTime`, `setMinimized`. `applyScroll` translates the label column to match `scrollY`. `reportView` writes the view to the file via `getDocumentEditor(world).reportEdit(scene, 'timeline', view)` (no history entry). |
| `surface.ts` | `TimelineSurface` koota trait holding one mutable `TimelineSurfaceState`: `canvas`, `ctx`, `pointer`, `layout` (parent `DOMRect`), `cursor`, `minimized`, `marquee`, `snapX`, `colors`. Render functions write `cursor`, `marquee`, `snapX` during the pass. |
| `pointer.ts` | `createPointer(options)`: immediate-mode hit testing. `down`/`move`/`up` track a `MousePosition` state machine (`idle` -> `pressed` -> `pressing` -> `lifted` -> `idle`). `scope(id).region(x, y, w, h, id?, passthrough?)` records the rectangle under the current canvas transform and returns `hovering`, `clicked`, `pressed`, `pressing`, `dragging` (past `CLICK_DISTANCE_THRESHOLD`), `doubleClicked` (within `DOUBLE_CLICK_THRESHOLD`), `intersectsMarquee`. Tests against the previous frame's regions; `reset()` swaps `next` into `prev`. Later non-passthrough regions win. |
| `view.ts` | Per-scene view state on the runtime `Timeline` trait store: `resolution` (pixels per frame), `scrollX` (frames), `scrollY` (pixels), `transform` (`DOMMatrix`). `ensureTimelineView` seeds defaults (`scrollX = -TIMELINE_PADDING_LEFT / resolution`). `updateTimelineTransform` rebuilds the matrix: dpr scale, minus scroll, plus `RULER_HEIGHT`. Helpers: `getTimelineScene` (= `getActiveEntity`), `framesToPixels`, `pixelsToFrames`, `getViewport`, `getCurrentFrame` (`Computed.localTime`), `getFrameRate`. |
| `layout.ts` | Row geometry shared by canvas and DOM labels: `RowCursor { top, height }`, `getNodeHeight` (`ClipHeight` trait or `DEFAULT_CLIP_HEIGHT`; keyframe rows `KEYFRAME_TRACK_HEIGHT`), `getSubtreeHeight`, `getRowsHeight`, `getRowTransform` (scene transform translated to the row top). Row tree itself comes from runtime `buildTimelineLayers`. |
| `drag.ts` | Clip move and trim gestures. State lives on entities as runtime traits `ClipDragOrigin` / `TrimDragOrigin` / `KeyframeDragOrigin`. `updateDragGestures` (once per frame): when the pointer is idle, removes origins and calls `resolveSequentialOverlaps` on moved clips; when a selected clip drags, snapshots the rest of the selection. `beginClipDrag`/`applyClipDrag` (`moveEntityTo`, floor at scene start, one shared snap via `findSnapDelta`). `beginTrim`/`applyTrim` (`trimIn`/`trimOut`, bounded by the other edge and by `findAssetDuration` / `playbackRate` / `origin`). `isDragging`. |
| `snapping.ts` | Snap targets in frames: scene start, playhead, and `Computed.start`/`end` of every node not moving (dragged clips, their ancestors and descendants, and `Selected` are excluded). `findSnapDelta` (nearest pairing of any dragged edge to any target within `SNAP_DISTANCE` px), `findSnapFrame` (single edge, for trims). |
| `media.ts` | Thumbnail decode cache outside the world. Stills (IMAGE, SEQUENCE first frame, MASK matte via `deriveThumbnail`): `resolveStill(asset, width)` decodes once per asset per tile width into an `OffscreenCanvas`. Video: asset layer `decodeSpread` (7 or 10 frames across the file via mediabunny `CanvasSink`); clip layer `updateClip` decodes only the visible tiles plus `TILE_MARGIN`, one decode per clip with a `pending` replacement. `requestFrames(FrameRequest)`, `pickFrame` (clip strip if covered, else spread). `cloneFramesForSplit`, `clearClipFrames`, `clearMedia`, `forgetAssetMedia`. |
| `peaks.ts` | Waveform peak cache outside the world. Asset layer `loadAsset` reads `Library.cache.waveform(asset)` (a `File` of one byte per peak at `WAVEFORM_PEAKS_PER_SECOND`). Clip layer `updateClip` slices `[from, to)` for the visible stretch plus `WINDOW_MARGIN = 0.5` and `downsamplePeaks` to the requested `peaksPerSecond`. `requestPeaks(world, PeakRequest)`, `getClipSamples(clip)`, `clonePeaksForSplit`, `clearClipPeaks`, `clearPeaks`, `forgetAssetPeaks`. `SAMPLE_WIDTH = 1`. |
| `style.ts` | `getClipStyle(entity, asset, errored)` picks a `COLORS.clip.*` palette by node type (caption, text, scene, group, clipPath, adjustment, html/surface paint) then asset type (VIDEO/SEQUENCE/MASK, IMAGE, AUDIO, else shape). `getClipFallbackName` gives the same cascade as words ("Captions", "Video", "Rectangle", "Layer"). `getClipAsset` = `findGeometryAsset`. |
| `text.ts` | `truncateText(ctx, text, maxWidth, font)`: ellipsis truncation by binary search, widths cached per `font-value`; cache cleared on `document.fonts` `loadingdone`. |
| `config.ts` | Numeric constants: clip heights (`MIN/MAX/DEFAULT_CLIP_HEIGHT`, `KEYFRAME_TRACK_HEIGHT`), `TIMELINE_RESOLUTION_RANGE`, `DEFAULT_TIMELINE_RESOLUTION`, wheel/zoom sensitivities, `SNAP_DISTANCE`, `TRIM_HANDLE_WIDTH`, click thresholds, `RULER_*`, `CLIP_*` label metrics, `CLIP_BREAKPOINTS`. |
| `constants.ts` | `RULER_INTERVALS` (major tick spans in frames with minor subdivisions, 600 s down to 5 frames) and the `COLORS` palette (background, border, ruler, one entry per clip kind). |
| `paths.ts` | `Path2D` shapes: `KNOB_PATH` (playhead), `IN_POINT_PATH`, `OUT_POINT_PATH` (work area handles). |
| `index.ts` | Barrel. Exports all of the above except `pointer.ts`, `paths.ts`, `text.ts`, `render/`. |

## How it works

- Setup: `engine/create-engine.ts` adds the `TimelineSurface` trait to the world at construction. `context/timeline.tsx` creates one controller per world; `components/timeline/timeline.tsx` calls `attachCanvas`/`detachCanvas` on mount/cleanup.
- Per frame: the `Engine` loop calls `timelineSystem(world)` after the runtime systems. The pass reads view state, closes or continues drag gestures, draws each layer, and each layer asks `pointer.region(...)` about the rectangle it just drew.
- Hit testing is one frame behind by design: `region()` matches the pointer against last frame's regions and records this frame's; `reset()` at the end of the pass swaps them.
- View state is per scene, on the runtime `Timeline` store (not `entity.set`), so scrolling is not an observable edit. The controller still reports it to the file as `<scene timeline>` through `reportEdit`, without history.
- Coordinates: runtime `Computed.start/end/origin` are frames; `view.ts` converts to pixels by `resolution`; `layout.ts` supplies the row transform; the canvas context transform makes render code work from the row's own (0, 0).
- Gestures write to the document, not the canvas: clip move/trim go through `engine/timing.ts` (`moveEntityTo`, `trimIn`, `trimOut`, `authoredTime`); on release `drag.ts` calls `engine/overlap.ts` `resolveSequentialOverlaps`. Selection, playhead, work area, and keyframe time edits happen inside `render/` via `DocumentEditor`.
- Snapping happens in frames: `drag.ts` asks `snapping.ts` for the nearest target and sets `surface.snapX`; `render/snap.ts` draws the line and clears it.
- Media is pulled lazily: `render/thumbnails.ts` calls `requestFrames`/`resolveStill`, `render/waveform.ts` calls `requestPeaks`; both draw only what `pickFrame`/`getClipSamples` already hold. Decodes are two-layered (asset-wide fallback, then clip-visible detail), one in flight per clip, latest request wins.
- Lifetime of caches: `create-engine.ts` clears a clip's frames and peaks when its `Geometry` is removed (`onRemove`), and clears everything in `dispose()`. `engine/split.tsx` clones a clip's strip and samples to the new half via `cloneFramesForSplit`/`clonePeaksForSplit`.
- DOM row labels (`components/timeline/layers`) use `layout.ts` heights and `config.ts` constants so canvas rows and label rows stay aligned; the controller translates the label column by `scrollY`.
