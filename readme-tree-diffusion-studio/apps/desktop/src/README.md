# `apps/desktop/src`

Electron main process and preload of the Diffusion Studio desktop app: window and IPC, project folders on disk (scaffold, compile, write-back, watch), the MCP server agents connect to, the agent-chat host process, and CLI/MCP registration on the user's machine.

## Parts

| Part | Role |
| --- | --- |
| `main.ts` | Entry. Order: `handleSquirrelEvent()`; Chromium switches (`CanvasDrawElement`, `SharedArrayBuffer`, no background throttling); load `dist/corner_radius.node` on darwin; `updateElectronApp({ repo: "diffusionstudio/editor" })` when packaged, not Squirrel, not `--hidden`; `new DapiServer({ version, logs: () => logBuffer, docsDir, onFirstConnection: enableHeadless })`; `setAsDefaultProtocolClient("diffusion")`; `requestSingleInstanceLock()` else `app.quit()`; register every `mainBridge.handle()`; `whenReady` boots services and `createWindow()`. Owns `logBuffer` (`LOG_BUFFER_MAX` 2000, fed by `console-message`, `preload-error`, `render-process-gone`), `pendingDeepLinks`, `openWrites` (streamed `FILE_WRITE_*`), `setFileInputFiles()` (CDP `DOM.setFileInputFiles` for `FILE_TRANSFER`), `WINDOW_CAPTURE` (`capturePage` to PNG bytes). |

| `main-channels.ts` | IPC contract. `MAIN_WIRE` = `main:request` / `main:response` / `main:event`. `MAIN_CHANNELS` = 43 renderer-to-main requests (`app:*`, `analytics:track`, `auth:*`, `checkout:*`, `window:*`, `file:*`, `logs:get`, `projects:*`, `agent-chat:endpoint`, `mcp:*`, `cli:*`) + 4 main-to-renderer events (`auth:callback`, `checkout:callback`, `window:fullscreen-change`, `projects:changed`). Typed maps `MainRequestMap`, `MainEventMap`; types `ProjectInfo { id, name, displayName, dir, entry, modifiedAt, createdAt }`, `CompileResult`, `McpStatus`/`McpAgentStatus`/`McpApplyRequest`/`McpApplyResult`, `CliStatus`/`CliInstallResult`/`CliUninstallResult`, `FsEntry`, `FsStat`, `DeepLinkChannel`, envelopes `MainRequest { id, channel, data }`, `MainReply`, `MainEvent`. Compile: `compileProject()`. Write: `writeProject()`. Assets: `MANIFEST_FILE` `assets.yml`, `readManifest()`/`writeManifest()` (YAML), `listEntries()`/`statEntry()`/`realPathEntry()` (`sourcePath()`: absolute paths pass, relative paths must stay inside the project), `removeEntry()` (project-relative only; refuses a target whose real path is outside the project). Config: `readConfig()`/`writeConfig()` on `package.json` `diffusion` field. Watch: `watchProject()`, `unwatchProject()`, `unwatchAll()`, `noteContent()`, `noteRenamed()`, `known` digest map, `DIGEST_MAX` 8 MiB. `load()` requires esbuild/babel from `Resources/runtime` when packaged. |
| `source.ts` | Read direction: three babel plugins. `canonicalizeTagsPlugin` rewrites camelCase composition tags (`COMPOSITION_TAGS`) to aliased PascalCase imports from `@diffusionstudio/jsx`; errors on `<Rect>` style tags and unimported Solid control flow (`For`, `Show`, ...); leaves `rect`/`text`/`image` alone under an SVG container. `inspectPlugin` turns `@inspect`-annotated top-level consts into `__inspect(declaration, literal)` calls and rewrites every value reference to an accessor call; `parseInspectComments()` validates `type` (`INSPECT_TYPES`), `min`/`max`/`step`, `path`/`label`, `options`. `sourcePlugin` numbers every JSX element in document order, removes `ID_ATTR`, stamps `SOURCE_ATTR` = `formatSource(file, id | position)` and `LOOP_ATTR` for elements inside `<For>`/`<Index>`. |
| `edit.ts`, `edit-types.ts` | Write direction. `edit-types.ts`: Node-free contract shared with the renderer: `SourceEdit` = `SourceSet` (`props`, `text`), `SourceInsert` (`parent`, `tag`, `before`), `SourceMove`, `SourceRemove`, `SourceUnroll` (`iterations: SourceIteration[]`), `SourceVariable` (`file`, `name`, `value: InspectValue`); `WriteResult { skipped, ids?, unrolled?, error? }`; `SourceContext { dir, onWrite }`. `edit.ts`: `SourceWriter` (ts-morph, in-memory fs, `skipLoadingLibFiles`). `applyEdits()` groups edits by file, loads, `dropUnparsed()` (syntactic diagnostics), `editFile()`, `save()` (only changed files, `onWrite` then `writeFileAtomic`). Per kind: `setProp()` (`muted` not `muted={true}`, absent for false, `generate.*`/`transform.*` via `declarationText()` + `ensureDeclarationImports()`), `setText()`, `insertElement()`, `moveElement()`, `removeElement()`, `unrollLoop()`, `setVariable()` (only when annotated and `isLiteral()`). `stampProject()` adds `ID_ATTR` (6 base-36 chars, `idAllocator()`) to every unnamed composition element. Refuses edits inside a loop (`inLoop()`) and nested-loop unrolls. Per file: a thrown edit or a syntax error after editing discards the whole file and skips all its edits. `tags()` walk order must equal `sourcePlugin` numbering. |

| `headless.ts` | `isHeadless()` / `enableHeadless()`. Module flag set by the MCP server's first non-chat session. Read by `projects.ts` `confirmCloudLocation()`. |

## How it works

- Boot (`main.ts`): Squirrel launch does housekeeping and quits. Otherwise `whenReady` runs `setupAppMenu()`, grants all permission handlers, delivers a `diffusion://` URL from argv, `dapi.start()`, `dapi.mcpUrl()` -> `startAgentChat({ mcpUrl: url + "?client=chat" })`, `refreshCliShim()`, `healMcpRegistrations()`, `trackInstall()`, `createWindow(!--hidden)`. `before-quit` runs `unwatchAll()`, `stopAgentChat()`, `dapi.stop()`.
- Window: `BrowserWindow` 1200x800 with `dist/preload.js`, `backgroundThrottling: false`. darwin: `hiddenInset`, vibrancy `sidebar`, transparent background, native corner radius and backdrop on create, `ready-to-show`, `show`; fullscreen sets radius 0 and emits `WINDOW_FULLSCREEN_CHANGE`. win32: hidden title bar + `titleBarOverlay` 40px, colours from `WINDOW_SET_COLOR_MODE`. Loads `http://localhost:5173` in dev, `web/index.html` packaged.
- Renderer to main: web sends `MAIN_WIRE.REQUEST { id, channel, data }` through `window.desktop.send`; `mainBridge` runs the handler for `channel` and replies on `MAIN_WIRE.RESPONSE` with the same `id`. Main pushes `MAIN_WIRE.EVENT { channel, data }` for deep links, fullscreen, and `PROJECTS_CHANGED`.
- Main to renderer tool calls go the other way on `DAPI_WIRE` (`dapi/renderer-calls.ts`); preload allowlists both wires.
- Project read path: `PROJECTS_COMPILE` -> `compileProject(dir)`: `findEntry()`, `ensureRecord()` (record fields only), `stampProject()` (ids into source, silent to the watcher via `onWrite` -> `noteContent()`), `projectBabelPlugins()` (project `babel.config.js`, plugins only), esbuild `build` (`bundle`, `cjs`, `chrome130`, externals `solid-js`, `@diffusionstudio/jsx`) with `solidLoader` plugin. Each project file: babel `[sourcePlugin, canonicalizeTagsPlugin, inspectPlugin, ...projectPlugins]` then `babel-preset-solid` (`generate: "universal"`, `moduleName: "@diffusionstudio/jsx"`) and `@babel/preset-typescript`. Returns `{ ok, code }` or `{ ok: false, error }`.
- Project write path: `PROJECTS_WRITE` -> `writeProject(dir, edits)` -> `applyEdits(sourceContext(dir), edits)`. Elements are located by `SOURCE_ATTR` value (`parseSource` -> file + id or position); `findTag()` returns nothing for an ambiguous id. New elements get ids at once; `WriteResult.ids` maps pending sources to real ones so the canvas re-stamps without a recompile. Loop bodies are refused unless a `SourceUnroll` copies the loop out first.
- Numbering invariant: `source.ts` counts every JSX element (components and DOM tags included) in babel traversal order; `edit.ts` `tags()` walks ts-morph in the same order. Position `n` must mean the same element in both.
- Watching: `watchProject()` uses `fs.watch(dir, { recursive: true })`; ignores `node_modules/`, `.diffusion/`, `.dstmp-*`. Events are digested serially (`digestOf()`: SHA-1, or `size:mtime` above 8 MiB) and emitted as `PROJECTS_CHANGED` only when the digest differs from `known`. Every own write claims its content first (`noteContent`, `noteRenamed`), so echoes are exact by content, not by timing.
- Streamed asset writes: `FILE_WRITE_OPEN` (mkdir, optional `wx` reservation, temp handle via `tempPathFor`) -> `FILE_WRITE_CHUNK` (positional write) -> `FILE_WRITE_CLOSE` (`noteRenamed(temp, path)` then `rename`) or `FILE_WRITE_ABORT` (unlink temp and reserved name).
- Cloud-sync guard: `defaultRoot()`, `pickRoot()`, `initProject()` call `confirmCloudLocation()`; a synced folder shows a warning dialog with "Use anyway"; headless runs log and continue.
- Agent path: `DapiServer` serves the `packages/dapi` catalog; `environment: "main"` tools run `dapi/handlers`; the rest cross `DAPI_WIRE` to `apps/web/src/dapi`. First session without `?client=chat` calls `enableHeadless()`.
- Agent chat: main forks the host, receives `listening` with a tokenized `ws://` URL, returns it on `AGENT_CHAT_ENDPOINT`; the renderer connects directly. `PROJECTS_DELETE` chains `deleteProjectChats(id)`.
- Settings: `MCP_STATUS`/`MCP_APPLY` -> `mcp-install.ts` -> `mcp-config.ts`; `CLI_STATUS`/`CLI_INSTALL`/`CLI_UNINSTALL` -> `cli-install.ts` (+ `cli-windows.ts`). Windows shims stay valid across Squirrel updates because they live outside the versioned app folder and are rewritten on every launch.
- Deep links: `diffusion://auth/callback` and `diffusion://checkout/callback` arrive via `open-url` (macOS) or `second-instance` argv (Windows); `deliverDeepLink()` emits at once or parks in `pendingDeepLinks` until `AUTH_GET_PENDING_CALLBACK` / `CHECKOUT_GET_PENDING_CALLBACK`.
- Analytics: renderer events arrive on `ANALYTICS_TRACK` because the Umami script does not fire on `file://`.

## Interfaces

- Depends on:
  - [../../../packages/dapi/](../../../packages/dapi/README.md) (`@diffusionstudio/dapi`): `MCP_URL`, `DAPI_WIRE`, `LogEntry`, `ScreenshotResult`, tool catalog (via `dapi/`).
  - [../../../packages/jsx/](../../../packages/jsx/README.md) (`@diffusionstudio/jsx`): `ID_ATTR`, `SOURCE_ATTR`, `LOOP_ATTR`, `INSPECT_TAG`, `INSPECT_TYPES`, `COMPOSITION_TAGS`, `isCompositionTag`, `isLoopTag`, `isSerializedAssetRef`, `isTransformType`, `parseSource`/`formatSource`, types `PropValue`, `SerializedAssetRef`, `InspectValue`, `InspectDeclaration`. Also the runtime module compiled projects import.
  - [../../../packages/agent-chat/](../../../packages/agent-chat/README.md): bundled to `dist/agent-host.mjs` by `build:agent-host`.
  - [../../../docs/](../../../docs/README.md): `INSTRUCTIONS.md` via `docsDir()` (`Resources/docs` packaged, repo `docs/` in dev).
  - [../scripts/](../scripts/README.md): `build-native.mjs` (addon), `stage-runtime.mjs` (esbuild/babel for `load()`), `stage-cli.mjs` (`Resources/cli/dapi.js`, `bin/dapi`), `stage-docs.mjs`.
  - npm: `electron` (`app`, `BrowserWindow`, `ipcMain`, `contextBridge`, `utilityProcess`, `dialog`, `shell`, `session`, `Menu`), `esbuild`, `@babel/core`, `babel-preset-solid`, `@babel/preset-typescript`, `ts-morph`, `nanoid`, `yaml`, `update-electron-app`, `@modelcontextprotocol/sdk` (in `dapi/`), `vitest`.
  - External binaries: `osascript` and `/usr/bin/xattr` (macOS), `powershell.exe` and `Update.exe` (Windows), `gh` (report tool).
- Used by:
  - [../../web/](../../web/README.md): `window.desktop` from `preload.ts` (`apps/web/src/lib/ipc.ts`); type-only imports via `@desktop/*` alias: `main-channels.ts`, `edit-types.ts`, `mcp-config.ts` (`AgentId`).
  - [../../cli/](../../cli/README.md) and external agents: over `MCP_URL` served by `dapi/`, or `dapi mcp` stdio proxy registered by `mcp-install.ts`.
  - `apps/desktop/package.json` `build`: esbuild bundles `main.ts` -> `dist/main.js` and `preload.ts` -> `dist/preload.js` (CJS; externals electron, esbuild, babel); `forge.config.ts` packages `dist/`.
