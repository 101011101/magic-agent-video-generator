# A-002 — Adopt user assets as roots
**Status:** open
**Cost:** saves 200 per adopted root
**Blocked by:** A-001

## Problem
Every root is generated today, even when the user gave the thing itself.

## Done when
An asset-sourced entity or place is copied into `roots/` unchanged (fit to 16:9 by padding, not cropping) and registered like a generated root; no image job runs for it.
