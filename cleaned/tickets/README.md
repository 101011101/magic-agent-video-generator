# Tickets

One ticket per file: `<ID>-<slug>.md`. IDs are stable. Prefixes: `B` build (stage 1), `V` video (stage 2), `A` asset bank and seeds (stage 0), `R` run (paid), `G` gap (known design hole).

Format: title line, then **Status** (open | in-progress | blocked | done), **Cost** (credits), **Blocked by**, then
`## Problem`, `## Done when`.
